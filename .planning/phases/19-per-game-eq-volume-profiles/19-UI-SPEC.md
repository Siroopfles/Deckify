# Phase 19 — UI Design Contract

> Visual and interaction contract for Phase 19: Per-Game EQ & Volume Profiles (`GAME-01`). Generated by `gsd-ui-researcher`, verified by `gsd-ui-checker`.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (`@decky/ui` manual SteamOS GamepadUI design system + inline style tokens) |
| Preset | not applicable |
| Component library | `@decky/ui` (`^4.11.1`) — `Focusable`, `DialogButton`, `DropdownItem`, `SliderField`, `ToggleField`, `TextField`, `ModalRoot`, `showModal`; in-repo `InteractiveRow`, `DeckifyImage`, and shared `renderEqBandFaders` |
| Icon library | `react-icons/fa` (`^5.5.0`) — `FaGamepad`, `FaPlus`, `FaTimes`, `FaTrash`, `FaSearch`, `FaMusic`, `FaSlidersH`, `FaUndo` |
| Font | SteamOS GamepadUI system sans-serif (`Motiva Sans`, `Arial`, `sans-serif` inherited from Steam CEF) |

> **System Constraints:** Deckify renders inside SteamOS GamepadUI CEF (`1280x800` handheld viewport and `1080p+` docked viewport). External CSS frameworks (`shadcn`, Tailwind) are absent (`components.json` not used). All external Steam/Spotify images route through `<DeckifyImage>` (`get_image` base64 proxy), and all horizontal controller strips MUST use `flow-children="horizontal"` (never `flow-children="row"`).

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Band-to-band gap in `EqBandFaders`, label-to-control gap inside fader columns, badge padding (`4px`), inline icon gaps |
| sm | 8px | Row gaps between EQ preset dropdown + `Edit Game EQ` button, slider-to-clear-button row gap, modal action button gap, `Copy from Preset` pill gap |
| md | 16px | `GameEqModal` container padding, modal section spacing, `SoundtracksTab` game card internal section separation |
| lg | 24px | Empty/loading state vertical padding, major modal header-to-faders separation |
| xl | 32px | Page/modal outer horizontal gutter and major layout breaks |
| 2xl | 48px | Game capsule thumbnail size (`48px × 48px` fallback/container alignment) and major block separation |
| 3xl | 64px | Page-level vertical breathing room |

Exceptions:
- `44px` minimum focus/touch target height for `DialogButton` and `InteractiveRow` primary actions (`Edit Game EQ`, `Save Game EQ`, `Discard Changes`, `Copy from Preset`, `Reset to Flat`, `Delete Game Profile`).
- `20px` minimum height on the compact `+` and `-` `0.5 dB` stepper rows inside `renderEqBandFaders` (`SettingsTab.tsx` & `GameEqModal.tsx`) so all 10 vertical ISO faders (`96px` track + numeric readout + steppers + frequency label) fit simultaneously without vertical scrolling inside the `82vh` modal on Steam Deck's `1280x800` screen.
- `12px` internal padding on existing `SoundtracksTab.tsx` game cards (`padding: 12px`, `gap: 12px`) to preserve alignment with existing Phase 07 game cards.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 12px | 700 | 1.3 |
| Body | 14px | 400 | 1.5 |
| Heading | 16px | 700 | 1.2 |
| Display | 20px | 700 | 1.2 |

- **Weights:** Strictly 2 weights across all Phase 19 additions — `400` (regular) for body copy, helper descriptions, search placeholders, and inactive captions; `700` (bold) for tab titles, modal/card headers, interactive button labels, preset pills, status badges, and `tabular-nums` EQ dB readouts.
- **Line-height:** `1.5` for `Body` descriptions and modal guidance; `1.2` for `Heading` and `Display`; `1.3` for `Label` badges, D-11 subtitle summaries, and EQ band readouts.
- **Role Mapping:**
  - `Display` (`20px`, `700`): `SoundtracksTab` & `SettingsTab` top page headings (`Game Soundtracks`, `Settings & Engine Features`).
  - `Heading` (`16px`, `700`): `GameEqModal` modal title (`{game.name} — Custom Game EQ`), game card titles, and `SettingsTab` card section headers.
  - `Body` (`14px`, `400`): Tab subtitle copy, `GameEqModal` live preview status description, empty/error guidance text, and `DropdownItem` / `SliderField` / `ToggleField` descriptions.
  - `Label` (`12px`, `700`): `"Running"` / `"Non-Steam"` / `"Active Game EQ Override: {app_name}"` / `"DUCKED"` / `"GAME VOL"` badges, D-11 inline audio override subtitle summary, `Preamp: -X.X dB` / `Bypass (0.0 dB)` indicator, EQ band dB values (`tabular-nums`), frequency labels (`31`–`16k`), and compact action button text.

5. Primary `"Save Game EQ"` CTA in `GameEqModal` and QAM live `"DUCKED"` / `"GAME VOL"` volume override indicator pill.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Edit Game EQ` (on game card when `EQ Preset Override` is `"Custom"`); `Save Game EQ` (primary commit action in `GameEqModal`); `Add Playlist / Album` (existing game card soundtrack action) |
| Secondary Modal & Clear Actions | `Copy from Preset` (preset seed picker inside `GameEqModal`); `Reset to Flat` (zero all 10 bands to `0.0 dB` inside `GameEqModal`); `Discard Changes` (close `GameEqModal` without saving); `Clear Volume Override` (reset `volume_override` to `null` / Disabled); `Use Global Ducking` (reset `ducking_level_override` to `null` / Use Global) |
| Empty state heading | `No Game Profiles Configured` (when search filter matches zero games or before any game is scanned) |
| Empty state body | Search filter empty: `No Steam or Non-Steam games matched your search. Clear the filter box above to browse all installed games.` Unbound game row subtitle: `No soundtrack or audio overrides configured`. `GameEqModal` neutral curve caption: `Flat Curve (0.0 dB) — Adjust any band slider or choose Copy from Preset to sculpt this game's EQ.` |
| Error state | Profile persistence failure toast: `Failed to save game audio profile — verify Decky storage permissions and try again.` Live EQ preview failure toast: `Equalizer preview unavailable — audio routed directly to hardware output. Check PipeWire status in Settings.` |
| Destructive confirmation | `Delete Game Profile` (`FaTrash`): Two-step inline confirmation on the game card — first activation swaps the button inline to **`Confirm Delete`** (red `#E53935`) alongside **`Keep Profile`**. Confirming calls `delete_game_soundtrack_profile`, immediately clears any live ephemeral override if that game is running, and displays toast `Game audio & soundtrack profile deleted` while leaving global EQ and volume settings intact. Switching `EQ Preset Override` to `Use Global` is non-destructive and preserves `eq_custom_bands` on the profile. |

### Inline Game Row Subtitle Copy Contract (`D-11`)
Generated deterministically by `formatGameProfileSubtitle(profile)` in `src/components/tabs/soundtrackUtils.ts`:
- `playlists.length > 0`: `"{N} linked soundtrack"` (`1`) or `"{N} linked soundtracks"` (`>1`)
- `playlists.length === 0` AND at least one audio override is set (`eq_preset != null || volume_override != null || ducking_override === false || ducking_level_override != null`): `"Audio profile only"`
- `playlists.length === 0` AND no audio override set: `"No soundtrack or audio overrides configured"`
- Appended override tokens (joined by `" • "`):
  - If `eq_preset != null`: `"EQ: {EQ_PRESET_LABELS[eq_preset]}"` (`Flat`, `Bass Boost`, `Vocal Clarity`, `Gaming Balance`, `Deck Speakers`, `Late Night`, `Custom`)
  - If `volume_override != null`: `"Vol: {volume_override}%"`
  - If `ducking_override === false`: `"Duck: Off"`
  - Else if `ducking_level_override != null`: `"Duck: {ducking_level_override}%"`

### Status Badge & Toast Copy
- `SettingsTab` Equalizer card override badge (`D-03`, shown only when `status?.active_game_override?.eq_preset` is active):
  - Badge text: `Active Game EQ Override: {app_name} ({presetLabel})` (truncated cleanly if `app_name` is long)
  - Helper caption underneath header when active: `Edits below update your global baseline and apply automatically after {app_name} exits.`
- QAM Volume header badge (`D-08`):
  - When `isDucked` is `true`: `DUCKED`
  - When `!isDucked && hasGameOverride` is `true`: `GAME VOL`

## Visual Hierarchy & Component Layout Contract

### 1. `SoundtracksTab.tsx` (Primary Screen)
- **Primary Visual Anchor:** When `runningAppId` matches an installed game, that game card pins to the top of the list (`sortGames`) with `#1DB954` tint/border and `"Running"` badge, auto-expanded (`expandedAppId === game.app_id`), drawing focus directly to its linked playlists and audio override controls. When idle, the `Filter installed games...` search bar and the first configured game card lead visual priority.
- **Expanded Game Card Section Order (top-to-bottom inside `<Focusable flow-children="column">`):**
  1. **Game Header (`InteractiveRow`):** `42px` capsule thumbnail (`DeckifyImage` with `FaGamepad` fallback), game name + `"Running"` / `"Non-Steam"` badges, and D-11 `formatGameProfileSubtitle(profile)` subtitle.
  2. **Assigned Playlists Row (`flow-children="horizontal"`):** Linked playlist chips + `Add Playlist / Album` button.
  3. **Playback / Resume / Exit Dropdowns Row (`flow-children="horizontal"`):** `Playback Mode`, `Resume Mode`, `On Game Exit`.
  4. **Per-Game EQ Override Row (`flow-children="horizontal"`, `D-01`):**
     - `EQ Preset Override` `DropdownItem` (`Use Global` mapped to `"global"` <-> `null`, plus `Flat`, `Bass Boost`, `Vocal Clarity`, `Gaming Balance`, `Deck Speakers`, `Late Night`, `Custom`).
     - Conditional **`Edit Game EQ`** `DialogButton` (with `FaSlidersH` icon, visible whenever `profile.eq_preset === "custom"`), opening `GameEqModal` via `showModal(...)` with `onPickerOpenChange(true/false)`.
  5. **Auto-Start & Ducking Override Toggles Row (`flow-children="horizontal"`):**
     - `Always auto-start soundtrack` `ToggleField`
     - `Ducking Override (Skip game ducking when off)` `ToggleField`
  6. **Volume Ceiling Override Row (`flow-children="horizontal"`, `D-06`):**
     - `SliderField`: `label` = `Volume Override (${profile.volume_override}%)` or `Volume Override (Disabled)` (`min={0}`, `max={100}`, `step={5}`, `showValue`).
     - Conditional **`Clear Volume Override`** `DialogButton` when `profile.volume_override !== null`.
  7. **Ducking Attenuation Override Row (`flow-children="horizontal"`, `D-06`):**
     - `SliderField`: `label` = `Ducking Attenuation Override (${profile.ducking_level_override}%)` or `Ducking Attenuation Override (Use Global)` (`min={0}`, `max={95}`, `step={5}`, `showValue`, `disabled={profile.ducking_override === false}`).
     - Conditional **`Use Global Ducking`** `DialogButton` when `profile.ducking_level_override !== null`.
  8. **Profile Footer Actions (`flow-children="horizontal"`):**
     - Conditional **`Delete Game Profile`** (`FaTrash`) inline two-step confirmation (`Confirm Delete` / `Keep Profile`) when `existingProfile` exists on disk.
- **Test Hook-Order & Live Refresh Guardrail:** Preserve the existing 5 top-level `useState` slots in `SoundtracksTab.tsx` (`games`, `profiles`, `searchQuery`, `expandedAppId`, `loading`) before adding any new state (e.g., `confirmDeleteAppId`) so existing hook-slot tests (`stateValues[2] === searchQuery`) remain intact. Pass `runningAppId={status?.active_game_app_id ?? null}` and global EQ baseline props (`globalEqPreset`, `globalEqCustomBands`) from `DeckifyExpandedModal.tsx:1230`.

### 2. `GameEqModal.tsx` + `src/components/common/EqBandFaders.tsx` (`D-01`, `D-02`)
- **Primary Visual Anchor:** The 10-band vertical ISO graphic fader strip (`31 Hz` to `16 kHz`, `-12.0` to `+12.0 dB` in `0.5 dB` steps) inside the `rgba(0,0,0,0.22)` recessed container, paired with the live Preamp headroom indicator in the modal header.
- **Modal Shell:** Wrapped in `@decky/ui` `ModalRoot` (`onCancel={handleDiscard}`, `closeModal={handleDiscard}`), `padding: 16`, `minWidth: 520`, `maxWidth: "90vw"`, `maxHeight: "82vh"`, `background: "#121212"`, `color: "#fff"`.
- **Header Row:** `{gameName} — Custom Game EQ` (`Heading` 16px) + live headroom readout (`Bypass (0.0 dB)` or `Preamp: -X.X dB`) + live preview caption (`Live PipeWire audio preview active` in `Body` 14px).
- **Quick-Seed Helper Bar (`D-02`):**
  - Label: `Copy from Preset`
  - Horizontal preset seed strip (`flow-children="horizontal"`, wrapping cleanly into 2 rows if needed): `Global`, `Flat`, `Bass Boost`, `Vocal Clarity`, `Gaming Balance`, `Deck Speakers`, `Late Night`, plus **`Reset to Flat`** (`FaUndo` icon + label) button.
  - Clicking any preset seed snaps all 10 modal sliders to that curve and fires `preview_eq_bands(nextBands)`.
- **10-Band Vertical Fader Strip (`renderEqBandFaders`):**
  - Extracted from `SettingsTab.tsx:531-673` as a plain render function `renderEqBandFaders(props)` (called directly inside both `SettingsTab.tsx` and `GameEqModal.tsx` so shallow JSX-tree tests in `SettingsTab.test.tsx` continue finding all 10 `role="slider"` elements without modification).
  - Horizontal strip (`flow-children="horizontal"`, `gap: 4`) of 10 vertical columns (`flow-children="column"`), each containing: `tabular-nums` dB readout (`12px`), `Increase {freq}` `+` `InteractiveRow`, vertical `24px × 96px` pointer-draggable `role="slider"` (`aria-valuemin={-12}`, `aria-valuemax={12}`, `aria-valuenow={gain}`), `Decrease {freq}` `-` `InteractiveRow`, and frequency short label (`31`–`16k`).
- **Footer Actions (`flow-children="horizontal"`):**
  - Left/Secondary: **`Discard Changes`** (`DialogButton`, `minHeight: 44`) — closes modal without saving; if `!isRunning`, calls `clear_eq_preview()` (if `isRunning`, restores the game's previously saved curve via `clear_eq_preview()`).
  - Right/Primary: **`Save Game EQ`** (`DialogButton` styled with `#1DB954` background and `#000` bold text, `minHeight: 44`) — commits `eq_preset: "custom"` and `eq_custom_bands: bands` immediately (bypassing the `500ms` save debounce so `EqualizerManager` promotes the active preview directly to `_ephemeral_bands` without a gap).

### 3. `SettingsTab.tsx` Equalizer Card Isolation (`D-03`)
- **Override Badge Placement:** Inside the `"Equalizer & Audio Presets"` card header row, render `"Active Game EQ Override: {app_name} ({presetLabel})"` as a compact `#1DB954`-tinted pill (`minWidth: 0`, `overflow: "hidden"`, `textOverflow: "ellipsis"`, `whiteSpace: "nowrap"`) whenever `status?.active_game_override?.eq_preset` is set, plus the non-blocking `Body` caption explaining that `SettingsTab` edits save to the global baseline while the game runs.

### 4. Quick Access Menu (`src/index.tsx`, `D-08`)
- Volume `SliderField` renders `effectiveVolume` whenever `(isDucked || hasGameOverride) && effectiveVolume != null`, displaying `"DUCKED"` when `isDucked` is true or `"GAME VOL"` when `hasGameOverride && !isDucked` is true.
