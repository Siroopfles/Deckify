<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `librespot --onevent` → `librespot-event.sh` → `LibrespotEventServer` | Subprocess env vars cross into local AF_UNIX socket and Python backend state |
| `SessionBookmarkManager` ↔ `session_bookmark.json` | Local filesystem persistence across abrupt Linux suspend/power transitions |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-17-01 | Tampering | `librespot-event.sh` & `LibrespotEventServer._handle_client` | medium | mitigate | Emitter uses `printf '%s\n'` with fixed env vars (no `eval`); Python parses strictly via `split("=", 1)` without shell execution, validates `PLAYER_EVENT`, and clamps `POSITION_MS`/`DURATION_MS`/`VOLUME` ints |
| T-17-02 | Denial of Service | `SessionBookmarkManager` (`session_bookmark.json`) | medium | mitigate | Atomic write via temp file + `os.replace()` prevents mid-suspend truncation; `JSONDecodeError` fallback prevents startup crash |
| T-17-03 | Information Disclosure | `ONEVENT_SOCK_FILE` (`onevent.sock`) | low | mitigate | Socket created inside `DECKY_PLUGIN_RUNTIME_DIR` with `os.chmod(sock_path, 0o600)` |
| T-17-SC | Tampering | Package installs | high | accept | Phase 17 introduces zero external npm, PyPI, or crates packages |
</threat_model>
