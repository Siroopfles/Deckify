## Interaction Contracts

### 1. Modal-Scoped Analog Trigger Controller (`DeckifyExpandedModal.tsx`)
- **Input Scope:** Active ONLY while `DeckifyExpandedModal` is mounted and open. Unmounts cleanly on modal close so in-game L2/R2 controls are never intercepted.
- **Schmidt Hysteresis & Debounce:** Analog trigger values (`0.0`–`1.0`) activate at `>= 0.75` and reset at `<= 0.25`, with `300ms` software debounce. Holding past `500ms` auto-repeats every `300ms`.
- **Suppression Guard:** Pause/suppress L2/R2 trigger actions whenever `ActionMenu` (`actionTrack`), `PlaylistPickerModal`, or any `INPUT`/`TEXTAREA` element has focus.
- **Content-Focus Guard:** In list views, L2/R2 fast-paging triggers ONLY when D-pad focus is inside the right-hand content pane; ignore L2/R2 list jumps while focus is inside the left `Sidebar`.
- **Reliable Modal Controller Actions (`Y` / `X` / Triggers):** Subscribe via `FocusNavController.m_rgGamepadInputSources[0].RegisterForGamepadButtonDown` (matching `src/index.tsx`) alongside existing keyboard/`vgp_onbuttondown` fallbacks so `Y` (open `ActionMenu`), `X` (toggle like), and `L2`/`R2` work consistently on focused list rows and on the active track in `NowPlayingTab` / `LyricsTab`.

### 2. L2/R2 Playback Seeking (`NowPlayingTab`, `LyricsTab`)
- **Accumulate & Debounce:** Consecutive L2 (`-step`) / R2 (`+step`) pulls accumulate into a single pending delta and debounce for `250ms` before dispatching one seek RPC.
- **Immediate Optimistic Preview:** Immediately update the seekbar preview position before the RPC resolves; clamp to `[0, duration_ms - 1000]` to prevent accidental track skips.
- **Focus Preservation:** Trigger seeking MUST NOT shift D-pad focus away from the currently focused UI control.
- **Floating Indicator Pill:** Display a centered bottom pill (`bottom: 24px` or above hint bar, `background: rgba(0,0,0,0.88)`, `border: 1px solid rgba(29,185,84,0.6)`, `borderRadius: 20px`, `padding: 8px 16px`, `fontSize: 12px`, `fontWeight: 700`, `color: #1db954`, `pointerEvents: "none"`) showing formatted delta (e.g. `+10s`, `+20s`, `-10s`) and fading out `~1000ms` after the last trigger pull.

### 3. Library Fast-Page Navigation (All List Views)
- **Covered Views:** `LikedSongsTab`, `PlaylistsTab`, `AlbumsTab`, `ArtistsTab`, `QueueTab`, `RecentTab`, `PodcastsTab`, `SoundtracksTab`, `SearchTab` results (outside text input), and Playlist/Album/Artist detail tracklists.
- **Smart Paging:** Jump `±pageSize` items (default `15`) in chronological/standard lists, or jump to the next/previous alphabetical letter anchor (`A → B → C`) when the active list is sorted A–Z.
- **Scroll + Focus Transfer:** Scroll the target row into view (`scrollIntoView({ block: "nearest" })`) AND transfer D-pad controller focus to that target row element.
- **Boundary & Short-List Behavior:** Clamp to `0` or `items.length - 1` (no wrap-around). If R2 is pulled at the end of a paginated list with `onLoadMore`, invoke `onLoadMore()`. In short lists (`items.length <= pageSize`), L2 jumps to `0` and R2 jumps to `items.length - 1`.
- **Floating Position Pill:** Reuse the same floating pill pattern showing `16 / 120` (item index / total) or anchor letter `M`, fading out after `~1000ms`.

### 4. Context-Aware Controller Hint Bar (`DeckifyExpandedModal.tsx`)
- **Placement:** Compact footer bar at the bottom of the modal (`padding: 8px 24px`, `background: rgba(0,0,0,0.65)`, `borderTop: 1px solid rgba(255,255,255,0.08)`, `fontSize: 12px`, `fontWeight: 700`, `color: rgba(255,255,255,0.7)`), toggleable via `show_controller_hints` in `SettingsTab.tsx`.
- **Context Copy:**
  - `now_playing` / `lyrics`: `L2/R2 Seek · X Like · Y Options · L1/R1 Tabs`
  - List tabs (`liked`, `playlists`, `albums`, `artists`, `queue`, `recent`, `episodes`, `soundtracks`, `search`): `L2/R2 Page · X Like · Y Options · L1/R1 Tabs`
  - Utility tabs (`devices`, `engine`): `L1/R1 Tabs · B Back`

### 5. Fixed Sidebar `Back to Steam (B)` Footer (`Sidebar.tsx`)
- **Structure:** Separate the scrollable navigation tab list (`flex: 1`, `overflowY: "auto"`) from a pinned footer container (`flexShrink: 0`, `borderTop: 1px solid rgba(255,255,255,0.08)`, `paddingTop: 8px`) inside a parent `<Focusable flow-children="column">` so D-pad Down from the last tab reliably focuses `Back to Steam (B)` and D-pad Up returns to the tab list.

### 6. `SettingsTab.tsx` Trigger Controls
- **Card Title:** `Controller & Trigger Navigation` (`14px`, `700`, `#1db954`).
- **Controls:**
  1. `L2/R2 Trigger Navigation` — toggle (`ON`/`OFF`, default `true`, key `trigger_nav_enabled`).
  2. `Controller Hint Bar` — toggle (`ON`/`OFF`, default `true`, key `show_controller_hints`).
  3. `Seek Step (Seconds)` — `@decky/ui` `SliderField` (`min={5}`, `max={30}`, `step={5}`, default `10`, key `trigger_seek_seconds`, `showValue`).
  4. `Library Page Jump (Items)` — `@decky/ui` `SliderField` (`min={5}`, `max={50}`, `step={5}`, default `15`, key `trigger_page_size`, `showValue`).

## UI Considerations

Applicable state considerations resolved via `ui-consideration-probe`: 8 resolved (explicit), 0 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| populated | E2 Floating Seek-Delta Pill | resolved (explicit) | Displays accumulated delta (`+10s`, `-10s`) immediately on L2/R2 pull and auto-fades after ~1000ms |
| populated | E3 Floating List Position Pill | resolved (explicit) | Displays `index / total` (e.g. `16 / 120`) or alphabetical anchor (`M`) on L2/R2 page jump and auto-fades after ~1000ms |
| empty | E3 List Fast-Page Handler | resolved (explicit) | Empty lists (`length === 0`) ignore L2/R2 page jumps with no pill shown and no focus error; empty views render the `## Copywriting Contract` empty-state copy |
| loading / error | E1, E2, E3 Seek & Paginate States | resolved (explicit) | Seek RPC failure displays the `## Copywriting Contract` error-state toast; pending/unloaded tracks ignore trigger seeks without crashing |
| overflow | E3 Track & List Boundaries | resolved (explicit) | Seek clamps to `[0, duration_ms - 1000]`; lists clamp to `[0, length - 1]`, call `onLoadMore` on R2 at end if available, and jump to start/end on short lists (`length <= pageSize`) |
| partial | E1 Sub-Modal / Input Suppression | resolved (explicit) | L2/R2 trigger actions are suppressed when `ActionMenu`, `PlaylistPickerModal`, text `INPUT`/`TEXTAREA`, or left `Sidebar` has focus |
| overflow | E5 Pinned Sidebar Footer | resolved (explicit) | `Back to Steam (B)` is pinned outside the scrollable sidebar list so it never scrolls off-screen and remains reachable via D-pad Down/Up |
| long-text / zero-one-many | E4 Context-Aware Hint Bar & E6 Settings Card | resolved (explicit) | Hint bar uses concise single-line `12px` labels per tab group with ellipsis/nowrap safety; `SettingsTab` toggles and `SliderField` controls render full labels cleanly at 44px+ row height |
