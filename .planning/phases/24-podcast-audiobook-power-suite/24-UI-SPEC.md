# Phase 24 — UI Design Contract

> Visual and interaction contract for Phase 24: Podcast & Audiobook Power Suite (`POD-01`, `POD-02`). Generated by `gsd-ui-researcher`, verified by `gsd-ui-checker`. Pre-populated from `24-CONTEXT.md` (D-01..D-09), `24-RESEARCH.md`, and the Phase 19–23 UI-SPECs (spacing/typography/color tokens reused unchanged).

## Design System

| Property | Value |
|----------|-------|
| Tool | none (`@decky/ui` manual SteamOS GamepadUI design system + inline style tokens; no `components.json`) |
| Preset | not applicable |
| Component library | `@decky/ui` (`^4.11.1`) — `Focusable`, `DialogButton`, `Dropdown`; in-repo `InteractiveRow`, `RoundBtn`, `DeckifyImage`, `focusHalo` |
| Icon library | `react-icons/fa` (`^5.5.0`) — `FaPodcast`, `FaUndo`, `FaRedo`, `FaPlay`, `FaPause`, `FaCheck`, `FaArrowLeft`, `FaTachometerAlt` |
| Font | SteamOS GamepadUI system sans-serif (`Motiva Sans`, `Arial`, `sans-serif` inherited from Steam CEF) |

> **System Constraints:** Renders inside SteamOS GamepadUI CEF (`1280x800` handheld viewport, `1080p+` docked viewport, and `300px` Quick Access Menu sidebar). External CSS frameworks (`shadcn`, Tailwind) are absent. Horizontal pill/filter bars and transport rows MUST use `<Focusable flow-children="horizontal">` (never `"row"`), and compact inline `DialogButton`s MUST set `width: "auto"` and `minWidth: "auto"` to override SteamOS 100% button width. All show/episode cover art MUST load through `DeckifyImage` (`get_image` base64 proxy) to satisfy Steam CEF CSP.

## Visual Hierarchy & Interaction Contract

### 1. `NowPlayingTab` Spoken-Content Transport & Speed `Dropdown` (`POD-01`; D-01, D-02, D-04, D-05, D-06)
- **Spoken Content Detection:** Uses `isSpokenContent(track)` (`media_type` in `["episode", "chapter", "audiobook"]`, URI contains `":episode:"` or `":chapter:"`, or legacy `album === "" && Boolean(name)` when `media_type` is undefined).
- **Transport Replacement (D-06):** When `isSpokenContent(track)` is `true`, the horizontal transport row (`<Focusable flow-children="horizontal">`) replaces `FaStepBackward` (Previous) and `FaStepForward` (Next) with dedicated `-15s` (`FaUndo` + `-15s`, `RoundBtn` `size={46}`, `onClick={() => handleSeekDelta(-15)}`) and `+15s` (`FaRedo` + `+15s`, `RoundBtn` `size={46}`, `onClick={() => handleSeekDelta(15)}`).
- **Speed `Dropdown` (D-01, D-02):** Rendered directly below the transport row when `isSpokenContent(track)` is `true` using `@decky/ui` `Dropdown`:
  - `rgOptions`: `["0.5x", "0.75x", "1.0x", "1.25x", "1.5x", "1.75x", "2.0x"]` mapped to numeric `data` (`0.5`..`2.0`).
  - `selectedOption`: current `playbackSpeed` (`1.0` default).
  - When `audio_backend !== "spotify_client"`, `Dropdown` renders `disabled={true}` with helper caption `Playback speed requires Official Spotify Client` (`12px`/`400`, `opacity: 0.6`).
- **Music Auto-Reset (D-05):** Transitioning to a standard music track automatically resets active speed to `1.0x` and hides the speed `Dropdown`, while preserving `preferred_podcast_speed` on the backend for the next spoken-word item.

### 2. Quick Access Menu (QAM) Compact Speed Cycle (`POD-01`; D-03)
- Inside `src/index.tsx` QAM's existing `isPodcast` horizontal row (`<Focusable flow-children="horizontal" style={{ display: "flex", justifyContent: "center", gap: 8, marginTop: 4 }}>`):
  - Left: `-15s` `DialogButton` (`width: "auto"`, `minWidth: "auto"`, `minHeight: 36`, `padding: "4px 8px"`).
  - Center: Speed Cycle `DialogButton` (`width: "auto"`, `minWidth: "auto"`, `minHeight: 36`, `padding: "4px 8px"`, `fontSize: 12`, `fontWeight: 700`) displaying `{playbackSpeed.toFixed(playbackSpeed % 0.5 === 0 && playbackSpeed % 1 === 0 ? 1 : ...)}` formatted via explicit lookup (`0.5x`, `0.75x`, `1.0x`, `1.25x`, `1.5x`, `1.75x`, `2.0x`).
  - Cycle order (D-03): `1.0x` → `1.25x` → `1.5x` → `1.75x` → `2.0x` → `0.5x` → `0.75x` → `1.0x`.
  - Right: `+15s` `DialogButton` (`width: "auto"`, `minWidth: "auto"`, `minHeight: 36`, `padding: "4px 8px"`).
  - Visual emphasis: When `playbackSpeed !== 1.0`, the Speed Cycle button displays `color: "var(--deckify-accent, #1DB954)"` and `border: "1px solid var(--deckify-accent, #1DB954)"`.

### 3. `DeckifyExpandedModal` `L2`/`R2` Smart-Skip & `usePlaybackClock` Scaling (`POD-01`; D-07)
- `DeckifyExpandedModal` stores `isSpokenRef.current = isSpokenContent(track)` on every render.
- In `useTriggerNavigation` `onTrigger`, when `isSpokenRef.current` is `true`, `L2` and `R2` seek `-15` / `+15` seconds per pull (accumulated inside `SEEK_ACCUMULATION_WINDOW_MS`), overriding `trigger_seek_seconds`.
- `usePlaybackClock` multiplies elapsed wall-clock time by `playbackSpeed` and re-anchors `(basePosition, syncTime)` whenever `playbackSpeed` changes so timestamps never jump or rubberband.

### 4. `PodcastsTab` Show Drill-Down, Progress Bars, Badges & Filtering (`POD-02`; D-08, D-09)
- **Show Drill-Down:** Clicking any show row in `Followed Podcasts` opens `ShowEpisodesView` with:
  - Header bar: `Back to Podcasts` `InteractiveRow` (`FaArrowLeft`) + show artwork (`DeckifyImage`, `42x42`) + show title (`Display` `20px`/`700`) + publisher/count (`12px`/`400`, `opacity: 0.6`).
  - Filter bar (`<Focusable flow-children="horizontal" style={{ display: "flex", gap: 8, marginBottom: 16 }}>`): `All`, `Unplayed`, `In Progress` (`minHeight: 36`, `padding: "4px 16px"`).
- **Saved Episodes Filter Bar:** Identical `<Focusable flow-children="horizontal">` `All` / `Unplayed` / `In Progress` filter pills rendered directly above the `Saved Episodes` list.
- **Episode Row (`InteractiveRow`, `minHeight: 44`, `gap: 8`):**
  - Left: `DeckifyImage` (`42x42`, `borderRadius: 6`, `flexShrink: 0`) or `FaPodcast` fallback.
  - Body (`flex: 1, minWidth: 0`):
    - Top line: Episode title (`Body` `14px`/`700`, single-line ellipsis).
    - Second line (`display: "flex", justifyContent: "space-between", alignItems: "center", gap: 8`):
      - Left: `{show_name} · {duration}` (`12px`/`400`, `opacity: 0.6`).
      - Right: `"Played"` badge (`12px`/`700`, `color: "var(--deckify-accent, #1DB954)"`) when `fully_played === true`, OR `"{N}m left"` / `"<1m left"` badge (`12px`/`700`, `color: "var(--deckify-accent, #1DB954)"`) when `!fully_played && resumeMs > 0`.
    - Bottom edge (when `fully_played || resumeMs > 0`): Thin progress bar (`height: 4`, `marginTop: 4`, `background: "rgba(255,255,255,0.15)"`, `borderRadius: 2`, `overflow: "hidden"`) with inner fill `width: ${pct}%` and `background: "var(--deckify-accent, #1DB954)"`.
