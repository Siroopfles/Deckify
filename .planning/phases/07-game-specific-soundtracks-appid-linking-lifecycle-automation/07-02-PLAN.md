<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Steam Client CEF Runtime → Deckify Plugin | AppLifetime event notifications received from SteamOS CEF bridge (`SteamClient.Apps`). |
| User D-Pad Input → UI State | Rapid controller inputs, search keystrokes, and modal open/close actions in GamepadUI. |
| External CDN URLs → Steam CEF DOM | Cover artwork URLs from Spotify and Steam CDN rendered in CEF WebView. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-04 | Denial of Service | `SoundtracksTab.tsx` / `PlaylistPickerModal.tsx` | medium | mitigate | Debounce search queries with 300ms delay, use memoized in-memory cached game lists, and prevent rapid repeated clicks from spawning concurrent RPC calls. |
| T-07-05 | Tampering | `src/index.tsx` (AppLifetime handler) | medium | mitigate | Track active debounce timers and cancel previous timer references immediately on state transitions, preventing orphaned callbacks or playback race conditions. |
| T-07-06 | Information Disclosure | `SoundtracksTab.tsx` | low | mitigate | Enforce Steam CEF CSP compliance by routing all game capsules and playlist covers through `fetchImageAsBase64` proxy, preventing CSP network errors or image leakages. |
| T-07-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero new external dependencies. Standard `@decky/ui`, `@decky/api`, and `react-icons` are reused without introducing third-party packages. |
</threat_model>
