   - Return `(buttons_0, buttons_1)` or `None` for other report IDs/lengths.

3. Implement `parse_evdev_event(raw: bytes, hat_state: dict[int, int | None]) -> list[tuple[int, bool]]`:

   - Uses `asyncio.get_running_loop().add_reader(fd, ...)` (with graceful fallback if `add_reader` is unsupported, e.g. Windows test runner) to read `os.read(fd, 64)` / `os.read(fd, 24 * 16)` non-blockingly when `enabled` is True.

   - Deduplicates `(button_id, pressed)` within `0.030` seconds (`time.monotonic()`) across open devices.
