## Interaction & Layout Contracts

1. **Controller Grab/Move Mode (`QueueTab` & User-Owned `PlaylistsTab`):**
   - Entry: Via `TrackActionModal` (`Y` → `"Move in Queue"` / `"Move Track"`) OR via inline `⇅` button on any upcoming queue row or editable playlist track row. Pressing `A` on the main row body continues to start playback immediately.
   - Focus Lock: Every row in `QueueTab` and `PlaylistsTab` carries a stable `_rowKey` string (`q:...`, `uid:...`, or `pl:...`) assigned once on list load and never derived from array index. Focus remains locked to `[data-row-key="..."]` while swapping.
   - D-Pad Navigation: While grabbed, `Focusable.onGamepadDirection` intercepts `DIR_UP` / `DIR_DOWN` (returning `true`), swaps the grabbed item by `±1` clamped to list bounds, and calls `scrollIntoView({ block: "nearest" })`.
   - Commit & Cancel: Pressing `A` commits a single batched reorder RPC (`reorder_queue_track` or `reorder_playlist_tracks`). Pressing `B` (`vgp_oncancel`) cancels Grab/Move Mode before modal/tab back navigation and restores the pre-grab list snapshot.
   - Trigger Suppression: `useTriggerNavigation` (`L1`/`R1`/`L2`/`R2`) is suppressed while Grab/Move Mode or any CRUD/Confirmation modal is active.

2. **Queue Studio Actions (`QueueTab`):**
   - `"Next in Queue (N)"` header uses `<Focusable flow-children="horizontal">` with inline 2-tap `"Clear Queue"` → `"Confirm Clear?"` + `"Cancel"` buttons (`width: "auto"`, `flexShrink: 0`).
   - Upcoming rows include inline `⇅` (Grab/Move) and `✕` (Remove from Queue) controls alongside existing `♥` and `⋯` controls.

3. **Playlist CRUD, Ownership & Filtering (`PlaylistsTab`, `CollectionActionModal`, `TrackActionModal`):**
   - `Edit Details` (`Name` required `<TextField>`, `Description` optional `<TextField>`) and `Delete Playlist` / `Unfollow Playlist` are exposed in both the Playlist Detail View header and `CollectionActionModal` (`Y` on any playlist row).
   - Non-empty playlist descriptions render beneath the playlist title in the Playlist Detail View header (`12px`, weight `400`, `opacity: 0.75`).
   - Read-only playlists (`is_editable === false`, e.g. `owner_id === "spotify"` or algorithmic mixes) hide `Edit Details`, `⇅`, and `✕`, and label deletion as `Unfollow Playlist`.
   - Local `<TextField>` search/filter bars appear at the top of `Folders & Playlists` overview, inside open Playlist Detail View, and inside `TrackActionModal`'s `"Add to Playlist..."` picker (which filters strictly to `is_editable !== false` playlists and includes `"+ New Playlist with Track"` at the top).
   - While a non-empty track filter is active inside Playlist Detail View, `⇅` Grab/Move Mode is hidden/disabled, and `originalIndex` from the unfiltered `playlistTracks` array is preserved for playback and single-instance removal.

## UI Considerations

Applicable state considerations resolved: 8 covered, 0 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | `QueueTab` upcoming list, `PlaylistsTab` filtered overview, `PlaylistsTab` filtered tracks, `TrackActionModal` playlist picker | ✅ covered | Empty states render the exact copy defined in `## Copywriting Contract` with clear next-step guidance. |
| loading | `PlaylistsTab` tracklist & CRUD submit buttons, `QueueTab` batched commit | ✅ covered | Loading/busy flags disable duplicate RPC submissions during network/CDP calls while preserving controller focus. |
| error | Playlist CRUD validation & backend mutation failures | ✅ covered | Empty playlist names show inline/toast validation copy; failed RPCs restore pre-mutation optimistic state and surface the `## Copywriting Contract` error copy. |
| populated | `QueueTab` upcoming rows, `PlaylistsTab` detail view & overview | ✅ covered | Rows render with stable `_rowKey` identity, ownership-gated inline `⇅` / `✕` actions, and horizontal header action bars (`flow-children="horizontal"`). |
| partial | `PlaylistsTab` active track filter | ✅ covered | Non-empty track filter hides/disables Grab/Move (`⇅`) to prevent ambiguous indices while preserving `originalIndex` for playback and single-instance removal. |
| long-text | Track titles, playlist names, playlist descriptions | ✅ covered | Single-line titles truncate with `textOverflow: "ellipsis"`, `whiteSpace: "nowrap"`, `minWidth: 0`; playlist descriptions wrap cleanly beneath the Detail View header. |
| zero-one-many | Duplicate track URIs in `QueueTab` and `PlaylistsTab` | ✅ covered | Unique `_rowKey` IDs (`q:...`, `uid:...`, `pl:...`) prevent React key collisions during Grab/Move and ensure single-instance removal preserves sibling duplicates. |
| grab-mode | Grabbed row in `QueueTab` / `PlaylistsTab` | ✅ covered | Active grab highlights the row with `var(--deckify-accent, #1DB954)`, locks `D-Pad Up/Down` via `onGamepadDirection`, updates hint bar to `"↑/↓ Move · A Drop · B Cancel"`, and restores pre-grab order on `B`. |
