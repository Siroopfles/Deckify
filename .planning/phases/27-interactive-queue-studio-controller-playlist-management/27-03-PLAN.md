## UI Considerations
- `populated`: `QueueTab` upcoming rows render with stable `_rowKey` identity (`key={t._rowKey}`, `data-row-key={t._rowKey}`) and compact inline `⇅` / `✕` controls (`width: "auto"`, `minWidth: "auto"`, `flexShrink: 0`, `minHeight: 36`).
- `grab-mode`: Active grab highlights the row with `1px solid var(--deckify-accent, #1DB954)`, intercepts `GamepadButton.DIR_UP`/`DIR_DOWN` via `onGamepadDirection` (returning `true`), auto-scrolls with `scrollIntoView({ block: "nearest" })`, commits on `A`, and restores pre-grab order on `B`.
- `empty` & `zero-one-many`: Empty queue displays `"Queue is empty. Add songs from your library or search."`; duplicate track URIs receive distinct `_rowKey` values (`q:...`, `uid:...`, `pl:...`).
