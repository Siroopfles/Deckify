    5. `cdp_remove_from_playlist(playlist_uri: str, track_uri: str, uid: str = "", port=..., timeout=..., eval_fn=None) -> dict`: calls `PlaylistAPI.remove(playlistUri, [uid ? { uri: trackUri, uid } : { uri: trackUri }])`.
    6. `cdp_add_to_playlist(playlist_uri: str, track_uris: list[str], port=..., timeout=..., eval_fn=None) -> dict`: calls `PlaylistAPI.add(playlistUri, uris, { after: 'end' })`.
