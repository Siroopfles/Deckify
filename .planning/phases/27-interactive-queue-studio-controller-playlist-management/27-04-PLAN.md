## UI Considerations
- `empty`: Filtered overview renders `"No playlists or folders match \"{query}\". Clear the filter to view all playlists."`; filtered detail view renders `"No tracks match \"{query}\". Clear the track filter to view all songs."`; filtered picker renders `"No editable playlists match \"{query}\". Select \"+ New Playlist with Track\" above to create one."`.
- `error`: Empty playlist name shows `"Playlist name cannot be empty. Enter a name to continue."` without submitting.
- `partial`: Non-empty detail track filter hides/disables `⇅` Grab/Move Mode and preserves `originalIndex` from unfiltered `playlistTracks` for playback and single-instance removal.
- `long-text`: Playlist descriptions wrap cleanly beneath the Detail View title (`12px`, weight `400`, `opacity: 0.75`); titles truncate with ellipsis and `minWidth: 0`.
