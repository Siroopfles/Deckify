## Warnings

### WR-01: Unmount cleanup in `SoundtracksTab` captures stale `onPickerOpenChange` closure (Medium)

**File:** `src/components/tabs/SoundtracksTab.tsx:92-99`
**Issue:** The mount `useEffect` has an empty dependency array `[]` and calls `onPickerOpenChange?.(false)` in its cleanup function. While `DeckifyExpandedModal` currently passes a stable `useState` setter (`setPlaylistPickerOpen`), `SoundtracksTabProps` is an exported component interface; if any caller passes a non-memoized callback, unmount cleanup will invoke the stale initial closure.
**Fix:** Store `onPickerOpenChange` in a `useRef` updated on render, and invoke `onPickerOpenChangeRef.current?.(false)` in the unmount cleanup:
```tsx
const onPickerOpenChangeRef = useRef(onPickerOpenChange);
onPickerOpenChangeRef.current = onPickerOpenChange;
// inside useEffect(() => { ... return () => { onPickerOpenChangeRef.current?.(false); ... }; }, []);
```

### WR-02: `playlistPickerOpen` can remain `true` if `PlaylistPickerModal` is dismissed without `onCancel`/`closeModal` (Medium)

**File:** `src/components/tabs/SoundtracksTab.tsx:133-137`
**Issue:** `SoundtracksTab` sets `onPickerOpenChange?.(true)` before calling `showModal(<PlaylistPickerModal onClose={() => onPickerOpenChange?.(false)} ... />)`. If Decky's modal manager unmounts `PlaylistPickerModal` externally (e.g., another `showModal()` replaces it on the stack or the modal is dismissed without firing `ModalRoot`'s `onCancel`/`closeModal`), `onClose` will not run while `SoundtracksTab` stays mounted, leaving `playlistPickerOpen === true` and suppressing L1/R1/L2/R2/X/Y navigation in `DeckifyExpandedModal` until the user switches tabs.
**Fix:** Add a unmount `useEffect` inside `PlaylistPickerModal` (or track whether `onClose` was already called with a ref) so `onClose?.()` is guaranteed to fire on modal unmount.
