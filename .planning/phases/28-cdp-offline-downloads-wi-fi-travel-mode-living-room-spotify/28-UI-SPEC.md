## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#121212` | Primary modal background, list views, detail headers |
| Secondary (30%) | `#1C1C1C` | Elevated sub-modals (`JamQrModal`, `EngineSwitchDownloadModal`, `BulkDeleteConfirmModal`), settings cards (`rgba(255,255,255,0.04)`), Travel Mode banner, sidebar |
| Accent (10%) | `var(--deckify-accent, #1DB954)` | Offline download progress/badges, Travel Mode pill, Jam Active badge, primary CTAs, `SettingsTab` card headings, focus halos |
| Destructive | `#FF5555` | Destructive actions only (`Remove All Offline Downloads`, `End Jam`, bulk delete confirm button) |

Accent reserved for:
1. Active offline download progress bars (`0–100%`), `↓ {pct}%` progress pills, and completed `✓` offline badges on playlists, albums, and podcast episodes
2. Active `"Offline Travel Mode"` header/sidebar pill and `"Jam Active"` status badge in `NowPlayingTab` and `DevicesTab`
3. Primary CTAs (`Download for Offline`, `Switch to Spotify Client & Download`, `Switch to Spotify Client & Start Jam`, `Start / Share Spotify Jam`) and focused `InteractiveRow` controller focus halos
4. `SettingsTab` Offline Downloads Manager and Travel Mode section headings (`h3`)

Special surface exception:
- `<JamQrCard>` renders `<QRCodeSVG value={qrUrl} size={180} bgColor="#FFFFFF" fgColor="#000000" level="M" />` inside a solid `#FFFFFF` quiet-zone wrapper (`padding: 16px`, `borderRadius: 12px`) so phone cameras scan reliably in dark theme (D-12).

## Visual Hierarchy & Accessibility

Primary focal points per new Phase 28 surface:
- **`JamQrModal` / `<JamQrCard>`:** High-contrast `#FFFFFF` quiet-zone `QRCodeSVG` (`180x180`) centered at top as the immediate living-room scan target, followed by the join URL, guest count badge, and horizontal action bar (`End Jam` / `Leave Jam` / `Close`).
- **Travel Mode library views (`PlaylistsTab`, `AlbumsTab`, `PodcastsTab`, `LikedSongsTab`):** Full-width `Offline Travel Mode` banner pinned at the top with 1-click `Exit Travel Mode` CTA, keeping focus on locally downloaded items below.
- **Offline Downloads Manager (`SettingsTab`):** Disk free-space readout (`{free_gb} GB free` vs `{min_free_gb} GB` minimum) and target storage path at top, followed by the selectable downloaded items list and guarded `Remove All Offline Downloads` button.
- **`EngineSwitchDownloadModal`:** Explanatory prompt body with primary focus on `Switch to Spotify Client & Download` and secondary `Stay on librespot` action.

Accessibility fallbacks for compact status indicators:
- Completed offline badge (`✓`): MUST include `aria-label="Downloaded for offline"` (and `title="Downloaded for offline"`).
- Active download progress badge (`↓ {pct}%`): MUST include `aria-label={`Downloading ${pct}%`}` (and `title={`Downloading ${pct}%`}`).

## UI Considerations

Applicable state considerations resolved: 5 covered, 1 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Offline Downloads Manager list, Travel Mode filtered tabs (`PlaylistsTab`, `AlbumsTab`, `PodcastsTab`, `LikedSongsTab`) | ✅ covered | Empty state renders documented `No offline downloads yet` heading/body and Travel Mode banner provides 1-click `Exit Travel Mode` action |
| loading | CDP offline download rows/headers (`0–100%`), `JamQrModal` session creation | ✅ covered | Rows show compact `↓ {pct}%` pill and headers show thin `4px` progress bar; `JamQrModal` shows loading state until `joinUrl` or `librespot` deep-link resolves |
| error | Disk guardrail (`os.statvfs < min_free_gb`), invalid storage path, CDP `OfflineAPI`/`SocialConnectAPI` unavailable | ✅ covered | Disk guardrail blocks/cancels active downloads with documented low-disk-space copy; `librespot` mode opens 1-click engine switch prompt rather than failing silently |
| populated | Downloaded items, active Jam session (`JamQrCard`, `NowPlayingTab`, `DevicesTab`) | ✅ covered | Downloaded items show accent `✓` badge; active Jam displays `Jam Active` pill (with guest count when available) and `#FFFFFF` quiet-zone `QRCodeSVG` |
| long-text | Custom `offline_storage_path`, Jam `joinUrl`, collection titles in detail headers | 🧪 backstop | Flex containers enforce `minWidth: 0`, `overflow: "hidden"`, and `textOverflow: "ellipsis"` so paths and titles never clip buttons in CEF |
| focus-navigation | `JamQrModal`, `EngineSwitchDownloadModal`, `BulkDeleteConfirmModal`, Travel Mode & Jam horizontal bars | ✅ covered | All new modals trap `vgp_oncancel`/`onCancelButton`, restore `previousFocusRef` on close, use `<Focusable flow-children="horizontal">`, and apply `width: "auto"` on compact buttons |
