<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User Settings → Flatpak CLI (`py_modules/engine.py`) | User-supplied `offline_storage_path` crosses into `flatpak override --user --filesystem=<path>` subprocess |
| Host Filesystem → `OfflineAPI` (`py_modules/common.py`) | Available disk space on target mount point gates download initiation |
| Local CDP WebSocket `127.0.0.1:9229` (`py_modules/cdp_bridge.py`) | Serialized `uri` strings injected into JS evaluation inside Spotify Client CEF |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-28-01 | Tampering | `configure_offline_storage_path` | high | mitigate | Reject empty, relative, null-byte, and newline inputs; pass list-form args to `_build_deck_command(["flatpak", "override", "--user", f"--filesystem={resolved}", SPOTIFY_FLATPAK_ID])` with `shell=False` and scoped directory (never `--filesystem=host`). |
| T-28-02 | Denial of Service | `check_disk_guardrail` | high | mitigate | Use `os.statvfs(target).f_bavail * st.f_frsize` (non-root blocks) and clamp `offline_min_free_gb` to `[0.5, 50.0]` GB (default `3.0`) so SteamOS never exhausts disk space. |
| T-28-03 | Tampering | `cdp_set_offline_download` | medium | mitigate | Serialize `uri` via `json.dumps(uri)` inside `evaluate_with_registry` so arbitrary quotes/JS cannot break out of string literals. |
| T-28-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero new external packages installed in Phase 28; verified in `28-RESEARCH.md` Package Legitimacy Audit. |
</threat_model>
