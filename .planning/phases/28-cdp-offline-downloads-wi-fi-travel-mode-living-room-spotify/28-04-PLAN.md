<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Frontend RPC → `main.py` | Untrusted RPC parameters (`uri`, `path`, `offline_min_free_gb`) enter Python `Plugin` handlers |
| Active Download Poll Loop → Host Disk (`main.py`) | Continuous download could fill SteamOS root/home partition if unmonitored |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-28-06 | Denial of Service | `main.py:_poll_playback` / `get_offline_status` | high | mitigate | Check `check_disk_guardrail` via `_exec` during active downloads; immediately pause/cancel active downloads and emit `low_disk_space` when free space drops below `offline_min_free_gb`. |
| T-28-07 | Denial of Service | `main.py` async event loop | medium | mitigate | Execute all `os.statvfs`, `flatpak override`, and CDP calls inside `await _exec(...)` so the Decky RPC loop never blocks. |
| T-28-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero new external packages installed in Phase 28. |
</threat_model>
