# Phase 21 — UI Design Contract

> Visual and interaction contract for Phase 21: Dynamic Album-Art Accent Themes & Handheld Battery Eco-Mode (`THEME-01`, `ECO-01`). Generated by `gsd-ui-researcher`, verified by `gsd-ui-checker`. ## Design System

| Property | Value |
|----------|-------|
| Tool | none (`@decky/ui` manual SteamOS GamepadUI design system + inline style tokens; no `components.json`) |
| Preset | not applicable |
| Component library | `@decky/ui` (`^4.11.1`) — `Focusable`, `DialogButton`, `ToggleField`, `SliderField`; in-repo `InteractiveRow`, `RoundBtn`, `focusHalo`, `DeckifyImage`, `SilentBanner`, `DeckifyOverlay`, `DeckifyExpandedModal` |
| Icon library | `react-icons/fa` (`^5.5.0`) — `FaPalette` (Accent Theme card header), `FaLeaf` / `FaBatteryHalf` (Handheld Battery Eco-Mode card header), `FaPlay` (QAM Wake & Play action), `FaMoon` (Engine Sleeping badge) |
| Font | SteamOS GamepadUI system sans-serif (`Motiva Sans`, `Arial`, `sans-serif` inherited from Steam CEF) |

> **System Constraints:** Renders inside SteamOS GamepadUI CEF (`1280x800` handheld viewport and `1080p+` docked viewport). External CSS frameworks (`shadcn`, Tailwind) are absent. All cover-art pixel sampling for `dynamic_album` MUST read from already-proxied `data:image/...` base64 URIs (`imgMemoryCache` / `fetchWithQueueAndCache`) — never external `https://i.scdn.co/...` URLs (Steam CEF CSP). All horizontal controller strips MUST use `flow-children="horizontal"` (never `"row"`), and compact inline `DialogButton` pills in `SettingsTab` MUST set `width: "auto"` and `minWidth: "auto"` to override SteamOS 100% button width.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#121212` | `DeckifyExpandedModal` surface, `SettingsTab` background, `DeckifyOverlay` (`rgba(18,18,18,0.88)`), `SilentBanner` (`rgba(18,18,18,0.92)`) |
| Secondary (30%) | `#1E1E1E` (`rgba(255,255,255,0.04)`–`rgba(255,255,255,0.08)`) | `SettingsTab` cards, unselected theme pills, `Bypassed` status badge surface, QAM card containers, inactive buttons |
| Accent (10%) | `var(--deckify-accent, #1DB954)` (`#1DB954` default; `#1A9FFF` SteamOS Blue; HSL `L >= 55%` clamped Dynamic Album Glow) | Reserved strictly for the enumerated elements below |
| Destructive | `#E53935` | Error-tone `SilentBanner` left rule only (no destructive actions in Phase 21) |

### Accent Theme Presets (`THEME-01`)
1. `spotify_green` — **Classic Spotify Green**: `#1DB954` (`rgb(29, 185, 84)`), default.
2. `dynamic_album` — **Dynamic Album Glow**: Dominant color extracted via `32x32` `<canvas>` downsampling on the active track's proxied `data:image/...` base64 artwork, vibrancy-weighted across 24 hue buckets, and clamped in HSL to `L ∈ [55%, 75%]` and `S >= 45%` for WCAG contrast on `#121212`/`#1E1E1E` dark SteamOS surfaces. Falls back to `#1DB954` when no track is playing, no artwork is available, or artwork is grayscale/low-saturation (`s < 0.18`).
3. `steamos_blue` — **SteamOS Deck Blue**: `#1A9FFF` (`rgb(26, 159, 255)`).

### Accent Reserved For (strictly enumerated)
1. Controller `focusHalo` ring (`0 0 0 2px #fff, 0 0 12px rgba(var(--deckify-accent-rgb, 29, 185, 84), 0.7)`) and `InteractiveRow` active/selected border and background tint.
2. Active `RoundBtn` primary transport (`Play/Pause`) background and active toggle icons (`Shuffle`, `Repeat`, `Like ♥`).
3. Active navigation sidebar tab indicator, selected preset/filter pills (including the active Accent Theme pill in `SettingsTab`), and `ToggleField` active state where styled.
4. Playback progress bars in `NowPlayingTab`, `DeckifyOverlay`, and `QuickAccessMenu`.
5. `SilentBanner` 3px left accent border on success/info tones (`error` retains `#E53935`, `neutral` retains `rgba(255,255,255,0.35)`).
6. Subtle radial background glow (`radial-gradient(circle at top right, rgba(var(--deckify-accent-rgb, 29, 185, 84), 0.18), transparent 65%)`) in `DeckifyExpandedModal` and `DeckifyOverlay`.
7. Active `On Battery — Active` Eco-Mode status badge border/text highlight in `SettingsTab`.

## Visual Hierarchy & Interaction Contract

### 1. Cross-Root CSS Custom Property Propagation (`THEME-01`)
- `DeckifyExpandedModal`, `QuickAccessMenu`, and `DeckifyOverlayWrapper` (`DeckifyOverlay` + `SilentBanner`) mount in separate React roots.
- A singleton theme controller (`src/utils/accentTheme.ts` + `src/utils/themeBus.ts`) computes the active `{ hex, rgb }` and writes three CSS custom properties onto `document.documentElement.style` (guarded by `typeof document !== "undefined"`):
  - `--deckify-accent`: active hex (`#1DB954`, `#1A9FFF`, or extracted `#rrggbb`)
  - `--deckify-accent-rgb`: `"r, g, b"` triplet for `rgba(...)` tinting
  - `--deckify-accent-transition`: `"color 350ms ease, background-color 350ms ease, border-color 350ms ease, box-shadow 350ms ease"` normally, or `"none"` when `eco_status.animations_suspended` is `true` (D-05).
- All CSS variable consumers retain `#1DB954` / `29, 185, 84` fallback values (`var(--deckify-accent, #1DB954)`) so existing JSDOM/Vitest unit tests continue to resolve valid colors.

### 2. Settings: `Accent Theme` Card (`SettingsTab.tsx`; D-06)
- **Placement:** Inside `SettingsTab` only (QAM stays compact). Positioned in the Appearance / General settings flow.
- **Controls:** A horizontal `Focusable flow-children="horizontal"` strip of 3 compact `DialogButton` pills (`width: "auto"`, `minWidth: "auto"`, `minHeight: 44`):
  1. `Classic Spotify Green` (with `10px` `#1DB954` color dot)
  2. `Dynamic Album Glow` (with `10px` dynamic/gradient color dot)
  3. `SteamOS Deck Blue` (with `10px` `#1A9FFF` color dot)
- Selecting a pill immediately updates `set_setting("accent_theme", ...)` and propagates `--deckify-accent` across Modal, QAM, and HUD within 1 frame (or `350ms ease` transition when animations are enabled).

### 3. Settings: `Handheld Battery Eco-Mode` Card (`SettingsTab.tsx`; D-08, D-11, D-12)
- **Header row:** `FaLeaf` / `FaBatteryHalf` icon + `Handheld Battery Eco-Mode` (`Heading` 16px/700) + right-aligned live status badge (`Label` 12px/700):
  - `Engine Sleeping`: amber/muted pill (`rgba(255, 193, 7, 0.16)` background, `1px solid rgba(255, 193, 7, 0.45)`, `#FFD54F` text)
  - `On Battery — Active`: accent pill (`rgba(var(--deckify-accent-rgb, 29, 185, 84), 0.16)` background, `1px solid rgba(var(--deckify-accent-rgb, 29, 185, 84), 0.45)`, `var(--deckify-accent, #1DB954)` text)
  - `Bypassed (AC / Docked / Desktop)`: secondary neutral pill (`rgba(255, 255, 255, 0.08)` background, `rgba(255, 255, 255, 0.72)` text)
- **Controls (top→bottom):**
  1. `ToggleField`: `Enable Battery Eco-Mode` (default `true`)
  2. `SliderField`: `Inactivity Sleep Timeout` (`min={5}`, `max={30}`, `step={5}`, `showValue`, suffix `min`, disabled/dimmed when `eco_mode_enabled` is `false`)
  3. `ToggleField`: `Sleep Official Spotify Client` (default `false`, disabled/dimmed when `eco_mode_enabled` is `false`)

### 4. Quick Access Menu: Eco-Sleep Indicator (`src/index.tsx`; D-12)
- When `eco_status?.engine_sleeping` is `true`, render a compact secondary-surface banner card (`padding: "12px 16px"`, `borderRadius: 8`, `background: "rgba(255, 255, 255, 0.06)"`, `border: "1px solid rgba(255, 193, 7, 0.35)"`) inside `QuickAccessMenu` showing `Eco-Sleep Active` (`Heading` 16px) + `Engine paused on battery to save power. Press Play to wake.` (`Body` 14px) and a `Wake & Play` `DialogButton` (`minHeight: 44`) that calls `control_playback("play")` to transparently wake the engine and resume playback.
- Standard QAM Play/Pause buttons also transparently wake the sleeping engine on press.

### 5. Animation Suspension Behavior (`animations_suspended`; D-05, D-10)
- When `eco_status?.animations_suspended` is `true` (on battery, undocked, active game running, Eco-Mode enabled):
  - `--deckify-accent-transition` is set to `"none"` (instant color switches, zero transition cost).
  - `DeckifyOverlay` disables entrance/exit slide/fade transitions and `deckifyLyricFadeIn` keyframe animation.
  - `DeckifyImage` suspends loading shimmer animation.
  - `eco_status.animations_suspended` is exposed for Phase 29's `TvSplitView` spectrum visualizer.
- **Preserved responsiveness:** `SilentBanner` visibility and controller `focusHalo` ring remain instant and fully responsive.
