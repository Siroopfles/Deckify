# Phase 22 — UI Design Contract

> Visual and interaction contract for Phase 22: Spotify Connect Hub 2.0 & Native Crossfade (`CONNECT-01`, `RADIO-02`). Generated by `gsd-ui-researcher`, verified by `gsd-ui-checker`. Pre-populated from `22-CONTEXT.md` (D-01..D-07), `22-RESEARCH.md`, and the Phase 19–21 UI-SPECs (spacing/typography/color tokens reused unchanged).

## Design System

| Property | Value |
|----------|-------|
| Tool | none (`@decky/ui` manual SteamOS GamepadUI design system + inline style tokens; no `components.json`) |
| Preset | not applicable |
| Component library | `@decky/ui` (`^4.11.1`) — `Focusable`, `DialogButton`, `SliderField`; in-repo `InteractiveRow`, `focusHalo` |
| Icon library | `react-icons/fa` (`^5.5.0`) — `FaGamepad`, `FaDesktop`, `FaMobileAlt`, `FaTabletAlt`, `FaVolumeUp`, `FaTv`, `FaCar`, `FaSpotify`, `FaSyncAlt`, `FaVolumeMute` |
| Font | SteamOS GamepadUI system sans-serif (`Motiva Sans`, `Arial`, `sans-serif` inherited from Steam CEF) |

> **System Constraints:** Renders inside SteamOS GamepadUI CEF (`1280x800` handheld viewport and `1080p+` docked viewport). External CSS frameworks (`shadcn`, Tailwind) are absent. All device icons MUST use `react-icons/fa` inline SVGs (never external URLs, which Steam CEF CSP blocks). Horizontal button strips MUST use `flow-children="horizontal"` (never `"row"`), and compact inline `DialogButton`s MUST set `width: "auto"` and `minWidth: "auto"` to override SteamOS 100% button width.

## Visual Hierarchy & Interaction Contract

### 1. `DevicesTab` Header & Pinned Local Steam Deck Card (`CONNECT-01`; D-01, D-02, D-03)
- **Header Row (`flow-children="horizontal"`):**
  - Left: `Spotify Connect Devices` (`Display` `20px`/`700`).
  - Right: Compact `Refresh` `DialogButton` (`FaSyncAlt` + `Refresh`, `width: "auto"`, `minWidth: "auto"`, `minHeight: 44`, disabled with `Refreshing...` while `isLoading`).
- **Pinned Local Steam Deck Status Card:**
  - Positioned at the top of `DevicesTab` above the remote device list (`padding: "12px 16px"`, `borderRadius: 10`, `background: "rgba(255,255,255,0.06)"`).
  - Displays `FaGamepad` (`18px`), local device name (`local_device_name`, default `"Deckify"`), inline engine pill badge (`librespot`, `spotifyd`, or `Spotify Client`), and current engine state (`Active`, `Ready`, `Sleeping`, or `Stopped`).
  - **1-click `"Pull Playback to Steam Deck"` CTA (`DialogButton`, `minHeight: 44`, `width: "auto"`, `minWidth: "auto"`):**
    - Shown whenever playback is active on an external Connect device OR the local engine is stopped/sleeping (hidden when the local Steam Deck device is already `is_active`).
    - On click: enters disabled `Pulling...` state, calls `pull_playback_to_deck()`, shows toast on error (`Could not pull playback to Steam Deck...`), and refreshes `get_devices()` on completion.

### 2. `DevicesTab` Device List & Icons (`CONNECT-01`; D-01, D-02)
- Each device in `devices` renders as an `InteractiveRow` (`minHeight: 44`, `padding: "12px 16px"`) inside `<Focusable flow-children="column" style={{ display: "flex", flexDirection: "column", gap: 8 }}>`.
- **Device Type Icon Mapping (`react-icons/fa`, `18px`, left column):**
  - Local Deckify device or `"GameConsole"` → `FaGamepad`
  - `"Computer"` → `FaDesktop`
  - `"Smartphone"` → `FaMobileAlt`
  - `"Tablet"` → `FaTabletAlt`
  - `"Speaker"`, `"AVR"`, `"CastAudio"`, `"AudioDongle"` → `FaVolumeUp`
  - `"TV"`, `"STB"`, `"CastVideo"` → `FaTv`
  - `"Automobile"` → `FaCar`
  - Fallback → `FaSpotify`
- **Row Content:**
  - Center (`minWidth: 0`, `flex: 1`): Device `name` (`14px`/`700`, `whiteSpace: "nowrap"`, `overflow: "hidden"`, `textOverflow: "ellipsis"`, colored `var(--deckify-accent, #1DB954)` when `is_active`) and subtitle (`12px`/`400`, `opacity: 0.65`) showing `{type}` + `· Active` / `· This Deck`. Local device row also includes the inline engine pill badge (`librespot` / `spotifyd` / `Spotify Client`).
  - Right (`flexShrink: 0`): `Active` badge when `d.is_active`, plus `Fixed Volume` pill (`FaVolumeMute` + `Fixed Volume`) when `d.volume_percent === null || d.is_restricted || d.supports_volume === false`.
- **Row Activation (`onClick`):** Selects the device (`selectedDeviceId`) and transfers playback (`transfer_playback(d.id)`), showing a toast and refreshing the list.

### 3. `DevicesTab` Debounced Remote Volume Slider (`CONNECT-01`; D-04, D-07)
- Rendered below the device list for the currently selected device (`selectedDeviceId`, defaulting to `devices.find(d => d.is_active)`).
- When `device.volume_percent !== null && !device.is_restricted && device.supports_volume !== false`:
  - Renders `@decky/ui` `SliderField` (`label="Remote Volume — {device.name}"`, `min={0}`, `max={100}`, `step={1}`, `showValue`, `valueSuffix="%"`).
  - `onChange` updates optimistic local volume state immediately and debounces `set_device_volume(device.id, val)` by `300ms` via `useRef<ReturnType<typeof setTimeout> | null>` (cleared on unmount). On `{ ok: false }`, reverts optimistic state and calls `showToast(...)`.
- When `device.volume_percent === null || device.is_restricted || device.supports_volume === false`:
  - Renders a non-interactive `Fixed Volume` status row (`FaVolumeMute` + `This device does not support remote volume control.`) instead of a `SliderField`.

### 4. `DevicesTab` Empty State (`CONNECT-01`; D-07)
- When `!isLoading && devices.length === 0`:
  - Renders a secondary-surface card (`padding: "16px"`, `borderRadius: 10`, `background: "rgba(255,255,255,0.04)"`) with `No Spotify Connect Devices Found` (`Heading` `16px`/`700`), helper body (`Body` `14px`/`400`), and a horizontal action strip (`flow-children="horizontal"`, `gap: 8`) with `Wake Local Engine` and `Refresh` (`DialogButton`, `width: "auto"`, `minWidth: "auto"`, `minHeight: 44`).

### 5. `SettingsTab` Crossfade Slider (`RADIO-02`; D-05, D-06)
- **Placement:** Inside `SettingsTab` -> `Playback & Audiophile Features` section.
- **Control:** `@decky/ui` `SliderField`:
  - `label`: `Crossfade`
  - `description`: `Smoothly blend between tracks (0s = Off). Syncs with Official Spotify Client and provides local PipeWire transition fallback for librespot.`
  - `min`: `0`, `max`: `12`, `step`: `1`, `showValue`, `valueSuffix`: `"s"` (reads `status?.settings?.crossfade_seconds ?? 0`).
  - `onChange`: Updates local UI state immediately and debounces `set_setting("crossfade_seconds", val)` by `300ms`, calling `showToast` on error.

## UI Considerations

Applicable state considerations resolved: 6 covered, 2 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | `DevicesTab` device list (`list-collection`) | ✅ covered | Empty `get_devices` response renders `No Spotify Connect Devices Found` card with `Wake Local Engine` and `Refresh` actions per `## Copywriting Contract`. |
| loading | `DevicesTab` initial load, `Refresh`, `Pull Playback` (`list-collection`, `interactive-control`) | ✅ covered | Initial load / refresh disables `Refresh` (`Refreshing...`); `Pull Playback to Steam Deck` transitions to disabled `Pulling...` while waking and polling `get_devices`. |
| error | `DevicesTab` RPCs & `SettingsTab` Crossfade slider (`interactive-control`, `form`) | ✅ covered | Failed `get_devices`, `pull_playback_to_deck`, `set_device_volume`, or `set_setting("crossfade_seconds")` surfaces error copy via `showToast(...)` and reverts optimistic volume state on failure. |
| populated | `DevicesTab` hub & `SettingsTab` Crossfade (`list-collection`, `interactive-control`) | ✅ covered | Renders pinned local Steam Deck card (`FaGamepad` + engine badge), device rows with type icons, debounced `Remote Volume` `SliderField`, and `SettingsTab` `Crossfade` `SliderField` (`0–12s`). |
| partial | `DevicesTab` fixed-volume / restricted devices (`list-collection`, `interactive-control`) | ✅ covered | Devices with `volume_percent === null`, `is_restricted`, or `supports_volume === false` render the `Fixed Volume` badge instead of an interactive `SliderField` and never call `set_device_volume`. |
| zero-one-many | `DevicesTab` device list (`list-collection`) | ✅ covered | Handles 0 devices (empty-state card), 1 device (local Steam Deck only — `Pull Playback` hidden when active), and N devices (pinned local card + remote list). |
| long-text | `DevicesTab` device names (`static-content`, `list-collection`) | 🧪 backstop | Long Connect device names truncate with `textOverflow: "ellipsis"` and `minWidth: 0` so right-aligned `Active` / `Fixed Volume` badges never wrap or clip. |
| overflow | `DevicesTab` many Connect devices (`list-collection`) | 🧪 backstop | Device list scrolls inside `DeckifyExpandedModal` `contentPaneRef` while preserving `flow-children="column"` D-pad focus navigation. |
