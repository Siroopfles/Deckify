## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GamepadUI `DevicesTab` → Python RPC (`set_device_volume`, `pull_playback_to_deck`) | User-triggered device IDs and slider values cross from React UI to Python backend |
| Python backend → Spotify Web API (`PUT /v1/me/player`, `PUT /v1/me/player/volume`) | Untrusted/arbitrary `device_id` strings or out-of-range volume values could cause malformed requests or HTTP 429 rate-limit floods |
