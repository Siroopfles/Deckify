    1. In `py_modules/volume.py`, create `VoiceActivityDetector(plugin, fader)`:
       - `check_recording_streams()`: runs `pactl list source-outputs` via `_build_deck_command`, parses blocks splitting by "Source Output #", filters out corked (`corked: yes`) or muted (`mute: yes`) streams, and checks for voice communication applications (matching `discord`, `steamcord`, `steam`, `steamwebhelper`, `webrtc`).
       - `_poll_loop()`: polls every 350ms while playing. When uncorked voice stream is detected, record `last_speech_time = time.monotonic()` and invoke `fader.set_ducking(True, reason="voice")`.
       - Silence hold hysteresis per D-03: when voice is not detected but `_voice_active` is true, check `time.monotonic() - last_speech_time >= hold_delay` (default 1.2s, configurable 0.5s–3.0s).        - Power throttling: if `voice_ducking_enabled` is false, sleep 2.0s; if `_is_playing` is false, sleep 1.0s.
    2. In `main.py`: instantiate `self._voice_detector = VoiceActivityDetector(self, self._volume_fader)` and start it in `_main()`; ensure `await self._voice_detector.stop()` is cleanly called in `_unload()`.
    3. In `tests/test_volume.py`, write unit tests for `VoiceActivityDetector`: test identifying active Discord stream, test ignoring corked/muted streams, and test that silence under 1.2s maintains ducked state while silence >= 1.2s releases ducking.
