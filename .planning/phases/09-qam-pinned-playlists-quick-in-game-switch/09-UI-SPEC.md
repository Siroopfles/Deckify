## Interaction Contracts

### 1. QAM Mini-Player Reorganization (`src/index.tsx`)
- **Primary Top Zone (1-click D-pad reach):**
  1. Compact Now Playing row (artwork, track name, artist/album, Playing/Paused status) + Seek slider (`durationSec > 0`)
  2. Transport Controls (`Shuffle`, `Prev`, `Play/Pause`, `Next`, `Repeat`, `Like`)
  3. **Pinned Playlist Pills** strip (directly below Transport Controls per D-02; hidden completely when `pinnedPlaylists.length === 0` per D-11)
- **Secondary Zone (Grouped & Collapsible below Primary Zone):**
  - `Volume` slider (with `DUCKED` badge)
  - `Bind current music to game` button (visible when `activeGameAppId !== null`): MUST render with a clearly visible SteamOS GamepadUI controller focus highlight (either `@decky/ui` `ButtonItem` or `DialogButton` without a conflicting `borderColor` override and with explicit focus ring styling, resolving the folded todo)
  - Collapsible / grouped secondary controls (`Playback Device` dropdown, `In-Game Overlay (HUD)` settings, `Engine` toggle, `Open Deckify (Full Screen)` button) so all existing QAM controls remain accessible without pushing playback and pinned playlists down.

### 2. Pinned Playlist Pills Strip (`src/index.tsx`)
- **Container:** `<Focusable flow-children="horizontal" style={{ display: "flex", alignItems: "center", gap: 8, overflowX: "auto", padding: "4px 2px", width: "100%" }}>` — MUST use `flow-children="horizontal"` (never `"row"`) for clean D-pad Left/Right traversal.
- **Pill Anatomy (per D-03, D-05):**
  - Compact horizontal pill (`minHeight: 36`, `maxWidth: 140`, `padding: "4px 8px"`, `borderRadius: 16`, `gap: 8`, `display: "inline-flex"`, `alignItems: "center"`, `flexShrink: 0`)
  - Square `20px × 20px` thumbnail (`borderRadius: 4`, `flexShrink: 0`) rendered via `DeckifyImage` / backend `py_modules/images.py` base64 proxy (fallback to `FaMusic` / `FaCompactDisc` / `FaHeart` `12px` icon if no `image_url`)
  - Single-line truncated name (`fontSize: 12`, `fontWeight: 700`, `lineHeight: 1.2`, `whiteSpace: "nowrap"`, `overflow: "hidden"`, `textOverflow: "ellipsis"`)
- **Active & Optimistic Playback State (per D-10):**
  - Highlighted with `#1db954` border + `rgba(29, 185, 84, 0.16)` background + `#1db954` text when `item.uri` matches active playback context or `optimisticContextUri`.
  - Clicking a pill immediately sets `optimisticContextUri`, preserves the user's current shuffle state (never forces shuffle ON), and invokes the quick context play RPC (which auto-wakes `librespot`/`spotifyd` if stopped so playback starts within 2 seconds).
  - On RPC failure, clear `optimisticContextUri` and show the documented Error state toast.

### 3. Pinning Workflow & Capacity (`PlaylistsTab`, `AlbumsTab`, `LikedSongsTab`, `TrackActionModal`)
- **Capacity:** `MAX_PINNED_PLAYLISTS = 4` (per D-06), persisted in `~/.config/deckify/settings.json` (`pinned_playlists`) in pin order (per D-12).
- **Supported Types:** Playlists (`"playlist"`), Albums (`"album"`), and Liked Songs (`"liked_songs"`).
- **Entry Point A — `Y` Action Menu / Context Action:**
  - `Pin to QAM` / `Unpin from QAM` option on playable playlist/album/collection items; when 4 items are already pinned and the target item is not pinned, show `Max 4 Pinned — Unpin One First` and trigger the limit-reached toast on select (per D-09, never auto-evict).
- **Entry Point B — Detail-View Header Toggle:**
  - Compact `FaThumbtack` toggle button in the header of `PlaylistsTab` detail view, `AlbumsTab` detail view, and `LikedSongsTab` header (`#1db954` active tint when pinned, neutral when unpinned).
- **Visual Pin Badge:** Pinned playlist/album rows in `PlaylistsTab` and `AlbumsTab` display a `12px` `#1db954` `FaThumbtack` badge.

## UI Considerations

Applicable state considerations resolved: 7 covered, 1 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | `pinned-pills-strip` | ✅ covered | When 0 items are pinned, the pinned pills section is hidden completely in QAM (no empty-state noise). |
| loading | `pinned-pill-button` | ✅ covered | Clicking a pill applies immediate optimistic active highlight while the backend auto-wakes the engine and starts context playback within 2s. |
| error | `pinned-pill-button` | ✅ covered | On quick-switch RPC failure, optimistic highlight rolls back and a Decky toast displays the documented Error state copy. |
| populated | `pinned-pills-strip` | ✅ covered | 1–4 pinned items render in pin order inside `<Focusable flow-children="horizontal">` directly below Transport Controls. |
| partial | `pinned-pill-button` | ✅ covered | If `image_url` is absent or proxy fails, a 20x20px fallback icon (`FaMusic`, `FaCompactDisc`, or `FaHeart`) renders without layout shift. |
| overflow | `pinned-pills-strip` | ✅ covered | Strip uses `overflowX: "auto"` with `flexShrink: 0` pills so up to 4 pills scroll cleanly via D-pad Left/Right inside the QAM width. |
| zero-one-many | `pinned-pills-strip` | ✅ covered | 0 hides section; 1–4 render horizontally; attempting a 5th pin is blocked without auto-eviction and shows the max-4 toast. |
| long-text | `pinned-pill-button` | 🧪 backstop | Long playlist/album names truncate to one line with `text-overflow: ellipsis` inside `maxWidth: 140px` without wrapping or clipping the 20x20px thumbnail. |
