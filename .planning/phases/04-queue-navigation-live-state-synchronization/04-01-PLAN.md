<objective>
Fix Queue track selection and live state synchronization so clicking any track in the queue starts playback of that exact track, immediately updates the Now Playing view, and refreshes the upcoming queue list with seamless gamepad focus retention.

### User Story
**As a** Steam Deck user managing playback from the Deckify modal,
**I want to** select any track from the queue to start playing it immediately,
**so that** the active track updates instantly in Now Playing and the queue advances without controller focus jumping to the sidebar.
