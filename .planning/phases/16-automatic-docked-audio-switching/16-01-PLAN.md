## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Frontend RPC (`set_setting`, `set_audio_sink`) -> `main.py` | Untrusted `dock_target_sink` / `sink_name` strings cross into `pactl` subprocess arguments |
| Root Decky process (UID 0) -> PipeWire/PulseAudio (`pactl`, `pw-metadata`) | Decky runs as root with bundled `LD_LIBRARY_PATH`; PipeWire runs under `deck` (UID 1000) |
| `pactl subscribe` stdout -> `DockAudioSwitcher` | Long-lived subprocess output triggers sink evaluation |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-16-01 | Tampering | `main.py:set_setting("dock_target_sink")`, `volume.set_audio_sink` | high | mitigate | Reject non-string, control-char (`ord(c) < 32 or ord(c) == 127`), or `-`-prefixed values; verify sink exists in `get_detailed_sinks()` before routing; pass args as `list[str]` without shell interpolation. |
| T-16-02 | Elevation / DoS | `py_modules/dock.py`, `py_modules/volume.py` | high | mitigate | Drop privileges to `DECK_UID` (1000) via `_build_deck_command()` and strip `LD_LIBRARY_PATH` before spawning `pactl` or `pw-metadata`. |
