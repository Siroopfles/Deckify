## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Python Backend → Spotify Client CEF (`127.0.0.1:9229`) | Untrusted/dynamic track IDs, playlist IDs, and URIs are interpolated into JavaScript evaluated via CDP `Runtime.evaluate`. |
| Python Backend → Local Disk (`~/.cache/deckify/discovery_mixes.json`) | Cached mix metadata and track URIs are written to and read from disk. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-26-01 | Tampering | `py_modules/cdp_bridge.py` (`Runtime.evaluate` JS) | medium | mitigate | Serialize every dynamic string/ID/URI into JS using `json.dumps(str(val))` rather than raw interpolation. |
| T-26-02 | Denial of Service | `py_modules/cdp_bridge.py` (port `9229` socket) | medium | mitigate | Enforce `DEFAULT_CDP_TIMEOUT = 4.0` and `is_spotify_client_running(plugin)` `0ms` fast-fail when `librespot` is active. |
</threat_model>
