    - Test 2 (`tests/test_resilience.py`): `is_device_dict_local(plugin, None)` returns `False` (missing device in player response is not assumed local), `is_local_device_active(plugin)` returns `True` when `_active_device is None` and `False` when `_active_device` is remote, and `handle_wake_recovery` yields (`held_reason="remote_active"`) both when `player_data` has `is_playing=True` with `device=None` and when `_fetch_current_player` returns `None` while `not is_local_device_active(plugin)`.
    - Test 3 (`tests/test_resilience.py` / `main.py`): `_poll_playback` updates `self._active_device` before `snapshot_from_state` and passes `was_playing=False` when the active device is remote.
    - Test 4 (`tests/test_soundtrack.py`): `SoundtrackManager._run_launch` with `soundtrack_unbound_policy == "pause"` does NOT call `self._pause()` when `not resilience.is_local_device_active(self.plugin)`.
  </behavior>
  <action>
    1. In `py_modules/resilience.py`:
       - Update `is_device_dict_local(plugin, device: dict | None) -> bool` to return `False` when `device` is `None`, not a `dict`, or has an empty `name`.
       - Update `is_local_device_active(plugin) -> bool` to return `True` when `getattr(plugin, "_active_device", None)` is `None` (no remote device active / idle local engine), and `is_device_dict_local(plugin, active_dev)` otherwise.
       - In `SessionBookmarkManager.handle_wake_recovery`:
         - If `player_data is None` and `not is_local_device_active(self._plugin)`: hold bookmark with `held_reason="remote_active"` and return without calling `_invoke_play_tracks`.
         - If `isinstance(player_data, dict) and player_data.get("is_playing")`: check `not is_device_dict_local(self._plugin, player_data.get("device"))` (so `device=None` or a remote device both yield with `held_reason="remote_active"`).
    2. In `py_modules/mpris.py`:
       - In `MprisBridge.sync_from_plugin`: if `not resilience.is_local_device_active(self._plugin)`, force `playback_status = "Stopped"` (and `NO_TRACK_PATH` metadata) so remote phone playback is never advertised as local `Playing`.
       - In `MprisBridge.handle_dbus_command`: for `method in ("Pause", "Stop")`, return immediately without calling `control_playback("pause")` if `not resilience.is_local_device_active(self._plugin)`.
    3. In `main.py:_poll_playback`:
       - Move the `device = data.get("device", {})` extraction and `self._active_device` update BEFORE `self._bookmark_manager.snapshot_from_state(...)` and `self._mpris_bridge.sync_from_plugin()`.
       - Compute `is_local = resilience.is_device_dict_local(self, device) if device else resilience.is_local_device_active(self)` and pass `was_playing=bool(is_playing and is_local)` to `snapshot_from_state`.
    4. In `py_modules/soundtrack.py`:
       - Import `resilience` (via `from py_modules import resilience` or existing module import pattern) and in `_run_launch` guard both `soundtrack_unbound_policy == "pause"` blocks with `resilience.is_local_device_active(self.plugin)` before calling `await self._pause()`.
    5. Add comprehensive unit tests in `tests/test_mpris.py`, `tests/test_resilience.py`, and `tests/test_soundtrack.py`.
