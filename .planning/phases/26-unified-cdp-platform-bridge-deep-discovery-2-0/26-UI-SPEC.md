## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Refresh Feed` (loading label: `Refreshing...`) |
| Empty state heading | `No personalized recommendations yet` (or `Rate limited` when `feed.rate_limited` is true) |
| Empty state body | `Play a few tracks or follow playlists on Spotify, then select Refresh Feed to populate your Discovery hub.` (or `Spotify rate limit cooldown active. Wait a moment and select Refresh Feed to try again.` when rate limited) |
| Search empty state | `No results found for "{query}". Try a different keyword or select a Gaming & Mood tile.` |
| Error state | `Rate limited — showing cached feed` (`discovery-stale-banner`); `Search unavailable — check your network connection and try again.` (`SearchTab` error banner) |
| Destructive confirmation | `Clear All` (`RecentSearchesSection` clears search history pills immediately; focused history pill supports `X/Y Remove`) |

Phase 26 interaction & microcopy contracts:
1. **Cached Mix Subtitle (`DiscoveryTab.tsx`):** When a *Made For You* mix is served from `~/.cache/deckify/discovery_mixes.json` while CDP is offline (`librespot` active or Spotify Client not running), append `" · Cached"` to `mix.subtitle` (e.g., `"Made for You · Cached"`, `"Playlist · Cached"`).
2. **Controller Hint Bar (`DeckifyExpandedModal.tsx`):**
   - `mode === "search"` and `focusedHistoryQuery` is non-null: `"A Search · X/Y Remove · L1/R1 Tabs"`
   - `mode === "search"` and `searchQuery.trim().length > 0` (and no focused history pill): `"A Select · B Clear Search · L1/R1 Tabs"`
   - `mode === "search"` and `searchQuery.trim().length === 0`: `"A Select · B Close · L1/R1 Tabs"`
   - `mode === "discovery"`: `"A Play/Open · Y Options · L1/R1 Tabs"`
3. **Optional CDP Browse Categories (`SearchTab.tsx`):** Section heading `Browse Categories`, rendered strictly below the 12 `Gaming & Mood` tiles (`Browse Gaming & Mood`) only when `get_search_browse_categories` returns non-empty items; completely omitted when `librespot` is active or CDP is unavailable.

## Interaction & Navigation Contracts

1. **Stepwise `B`-Button Navigation in `SearchTab` (`DeckifyExpandedModal.tsx` `vgp_oncancel`):**
   - Step 1: If `actionTrack` or `actionCollection` modal is open, close that modal.
   - Step 2: If `navigationHistoryRef.current.length > 0` (e.g., drilled down from Search results into an Artist, Album, Playlist, or Show), pop `navigationHistoryRef` and restore `SearchTab` with `searchQuery`, `searchResults`, scroll position, and focus intact.
   - Step 3: If `modeRef.current === "search"` and `searchQueryRef.current.trim().length > 0`, intercept `B` (`e.preventDefault()`, `e.stopPropagation()`, `stopImmediatePropagation?.()`), reset `searchQuery` to `""`, `searchResults` to `{}`, `tileSearchMode` to `false`, and `searchOffset` to `0`, returning to the Search idle screen (`Recent Searches` + 12 `Gaming & Mood` tiles).
   - Step 4: If `searchQuery` is already empty on the Search idle screen, allow `B` to close the Deckify modal normally.
2. **Spatial Navigation & CSP Compliance:**
   - All horizontal carousels (`Made For You`, `Top Tracks`, `Recent Searches`, `GamingMoodGrid` rows, optional `Browse Categories` rows) MUST use `<Focusable flow-children="horizontal">`.
   - All Spotify artwork URLs (`spotify:image:`, `spotify:mosaic:`, `https://i.scdn.co/image/`) MUST be normalized in Python and rendered exclusively via `<DeckifyImage>` (base64 proxy) to comply with Steam CEF CSP.
   - Activating any *Made For You* mix card in `DiscoveryTab` opens `PlaylistsTab` (`onOpenPlaylist(mix)`), and pressing `Y` on a focused mix opens `CollectionActionModal` (`onFocusCollection`), working identically on both `spotify_client` and `librespot` (via `~/.cache/deckify/discovery_mixes.json`).
