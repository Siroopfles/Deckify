<objective>
Implement live playback clock interpolation and responsive gamepad seekbar scrubbing across Deckify's Now Playing views (expanded modal and Quick Access Menu).

### User Story
**As a** Steam Deck user listening to Spotify via Deckify,
**I want to** see smooth real-time elapsed playback time without rubberbanding and scrub tracks directly using the D-pad,
**so that** my Now Playing progress is always accurate, jitter-free, and responsive to controller navigation.

Purpose: Eliminate the 200–600ms second-counter rubberbanding caused by raw server status polling, provide a smooth 250ms UI ticker, enable direct D-pad Left/Right seekbar scrubbing with a visible thumb handle and focus halo, debounce seek RPC requests to 300ms to protect Spotify Web API rate limits, and suppress stale post-seek server position snapshots for 1500ms.
Output: `src/hooks/usePlaybackClock.ts`, `src/hooks/usePlaybackClock.test.ts`, updated `src/hooks/usePlaybackStatus.ts`, updated `src/components/tabs/NowPlayingTab.tsx`, and updated `src/index.tsx`.
</objective>
