## Overview

Milestone v0.4 resolved major stability, architectural technical debt, UI/audio desynchronization, and SteamOS CEF compatibility hurdles in Deckify. Monolithic frontend and backend codebases were cleanly decoupled into modular submodules, Spotify CDN image proxying and concurrency throttling were stabilized, live playback clock interpolation and controller seek scrubbing were built, queue playback selection was fixed with explicit URI sequences, and the in-game HUD overlay was restored with strict non-blocking input handling and direct Quick Access Menu controls.

## Milestone Summary

**Key Decisions:**
- **D-01 (Explicit Sliced URIs Sequence & Backend Alias):** Frontend binds `backendPlayTracks` to `play_tracks` passing explicit sliced URIs sequence; backend exposes `play_track = play_tracks`, `toggle_like = toggle_like_track`, and `set_native_mix = set_native_playlist_mix` for bidirectional RPC compatibility.
- **D-02 (QueueTab Visual Hierarchy):** Added dedicated top Now Playing card with 48x48 artwork, green/neutral pill badge, track metadata, and formatted duration.
- **D-03 (Immediate Optimistic Mutation & 600ms Resync):** Selecting a queue track slices upcoming list and promotes active status immediately; schedules 600ms delayed background queue resynchronization to let Spotify server pointer settle.
- **D-04 (GamepadUI Focus Preservation):** Wrapped upcoming queue tracks inside `<Focusable flow-children="column">` with stable keying (`t.id || t.uri || idx`) preserving controller focus without jumping to sidebar.
- **D-05 (Concurrent Dual-Signal Polling):** `DeckifyOverlayWrapper` concurrently synchronizes track metadata, `isPlaying`, settings, `positionMs`, and `durationMs` via push events with a 4s fallback loop, preventing HUD freezes when background events are missed.
- **D-06 (Strict Non-Intercepting Container):** Root HUD overlay container strictly enforces `pointerEvents: "none"`, `position: "fixed"`, `zIndex: 9999` to guarantee touch and controller inputs pass directly through to gamescope games.
- **D-07 (Live Clock Interpolation):** Built `usePlaybackClock` with 250ms monotonic time interpolation and 1200ms drift gating, plus a 1500ms post-seek suppression window.

**Issues Resolved:**
- Decoupled ~2,959 LOC `DeckifyExpandedModal.tsx` and ~2,600 LOC `main.py` without breaking existing feature parity or 325 backend unit tests.
- Eliminated Steam CEF CSP image blocking and RPC thread starvation through client-side request queues and in-memory LRU caching.
- Fixed stagnant progress bars and seekbar rubberbanding during playback.
- Fixed queue clicking jumping to track 0 or failing to update Now Playing.
- Restored floating in-game HUD overlay with 6s auto-hide, 3.5s pause grace, 2px bottom progress bar, and QAM controls.

**Technical Debt Incurred:**
- None. All test suites pass cleanly (55 Vitest tests, 0 TypeScript errors, 325 Python unit/E2E tests).
