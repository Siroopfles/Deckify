## Architecture Patterns

### Pattern 1: Lossless + `bit_perfect_clock` Gating in Backend (`py_modules/dock.py` & `main.py`)
**What:** Across Deckify, PipeWire `clock.allowed-rates` unlocking is gated on BOTH `audio_quality == "lossless"` AND `bit_perfect_clock` being truthy.
**Verified call sites:**
- `main.py:388-392`:
  ```python
  is_lossless = (
      self._settings.get("audio_quality") == "lossless"
      and bool(self._settings.get("bit_perfect_clock", True))
  )
  await self._configure_pipewire_clock(is_lossless)
  ```
- `main.py:812-815`:
  ```python
  await self._configure_pipewire_clock(
      self._settings.get("audio_quality") == "lossless"
      and bool(self._settings.get("bit_perfect_clock", True))
  )
  ```
- `py_modules/dock.py:313-316` (current buggy code):
  ```python
  await volume.set_audio_sink(restored_sink, plugin=self._plugin, is_auto_dock=True)
  await volume.configure_pipewire_clock(False)

  settings = getattr(self._plugin, "_settings", {}) or {}
  ```
- `py_modules/dock.py:399-400` (on dock):
  ```python
  if bool(settings.get("bit_perfect_clock", True)):
      await volume.configure_pipewire_clock(True)
  ```
**Target fix in `DockAudioSwitcher._restore_pre_dock()` (per D-01):**
Move `settings = getattr(self._plugin, "_settings", {}) or {}` above the `configure_pipewire_clock` call and only reset the clock when lossless + `bit_perfect_clock` is not active:
```python
        settings = getattr(self._plugin, "_settings", {}) or {}
        restored_label = self._resolve_sink_label(restored_sink, sinks)
        await volume.set_audio_sink(restored_sink, plugin=self._plugin, is_auto_dock=True)
        preserve_lossless_clock = (
            settings.get("audio_quality") == "lossless"
            and bool(settings.get("bit_perfect_clock", False))
        )
        if not preserve_lossless_clock:
            await volume.configure_pipewire_clock(False)
```
**Why `bit_perfect_clock` default `False` in `.get("bit_perfect_clock", False)` matters:**
- In production, `Plugin._settings` is populated from `common.DEFAULT_SETTINGS`, where `"bit_perfect_clock": True` `[VERIFIED: py_modules/common.py:78]`.
- In existing unit tests (`tests/test_dock.py:97-104`, `177-182`, `212-219`), `_settings` omits `"audio_quality"`, so `settings.get("audio_quality") == "lossless"` evaluates to `False`, and `configure_pipewire_clock(False)` is still called — keeping all 3 existing undock tests (`test_dock_usb_and_undock_restores_pre_dock_and_clock`, `test_undock_falls_back_to_default_sink_token_when_pre_dock_missing`, `test_7_disable_while_docked_restores_sink_and_clock`) green without breaking existing assertions.
- Note: Also check whether `audio_quality == "lossless"` + `bit_perfect_clock=False` should call `configure_pipewire_clock(False)` — yes, `preserve_lossless_clock` is `False`, so it resets to `48000` Hz.

## Common Pitfalls

### Pitfall 1: `settings` Read Position in `_restore_pre_dock()`
**What goes wrong:** Reading `settings` on line 316 after `configure_pipewire_clock(False)` on line 314 causes `NameError` or stale check if not moved up.
**How to avoid:** Move `settings = getattr(self._plugin, "_settings", {}) or {}` above `configure_pipewire_clock` in `_restore_pre_dock()`.

### Pitfall 2: `on_settings_changed("dock_auto_switch_enabled", False)` While Docked
**What goes wrong:** Disabling dock auto-switching while docked calls `self._restore_pre_dock(sinks, default_sink, skip_pause=True)` (`py_modules/dock.py:251`).
**How to avoid:** Because `_restore_pre_dock` is the single shared undock restoration path, guarding `configure_pipewire_clock(False)` inside `_restore_pre_dock` automatically fixes both physical undock (`evaluate_now()`) and toggle-off-while-docked (`on_settings_changed()`).

### Pitfall 3: `15-VALIDATION.md` and `16-VALIDATION.md` Use `py -m unittest` vs `py -3 -m unittest`
**What goes wrong:** Windows/CI environments may alias `py` or `py -3`; `package.json` uses `py` or `python3`, while `13-VALIDATION.md` uses `py -3 -m unittest`.
**How to avoid:** Keep commands consistent and executable on the dev host (`py -3 -m unittest ...`), and run every command verbatim before marking `✅ green`.
