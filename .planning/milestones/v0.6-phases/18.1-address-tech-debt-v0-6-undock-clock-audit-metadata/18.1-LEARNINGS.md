# Phase 18.1 Learnings: Address tech debt: v0.6 undock clock & audit metadata (INSERTED)

## Decisions

### Undock PipeWire Clock Guard
Guard `volume.configure_pipewire_clock(False)` in `DockAudioSwitcher._restore_pre_dock()` with `preserve_lossless_clock = settings.get("audio_quality") == "lossless" and bool(settings.get("bit_perfect_clock", False))` so undocking (and disabling `dock_auto_switch_enabled` while docked) preserves `bit_perfect_clock` when lossless + bit-perfect clock is active, and resets to 48000 Hz otherwise.

**Rationale:** Prevents undocking from silently clobbering the user's lossless `bit_perfect_clock` configuration while still resetting non-lossless or disabled-clock sessions cleanly.
**Source:** 18.1-01-PLAN.md, 18.1-01-SUMMARY.md

## Lessons

### Windows PowerShell 5.1 Command Chaining
Using `&&` in Windows PowerShell 5.1 fails; chaining multi-step verification commands on Windows requires `; if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE };` instead.

**Context:** Observed during Phase 18.1 Plan 02 Task 1 execution when running sequential `py -3 -m unittest` and `pnpm test` suites.
**Source:** 18.1-02-SUMMARY.md

---

### Disabling Auto-Switch While Docked Shares `_restore_pre_dock()` Path
`on_settings_changed("dock_auto_switch_enabled", False)` delegates to `_restore_pre_dock()`, so guarding `configure_pipewire_clock(False)` inside `_restore_pre_dock()` resolved both physical undocking and disabling dock auto-switching while docked.

**Context:** Verified by `test_12_disable_while_docked_preserves_clock_when_lossless_and_bit_perfect_enabled` in `tests/test_dock.py`.
**Source:** 18.1-01-PLAN.md, 18.1-VERIFICATION.md
