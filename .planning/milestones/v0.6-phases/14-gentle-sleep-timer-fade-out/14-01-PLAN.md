- Unresolved probe item for `SLEEP-01` (`unclassified — review manually`): Because `14-CONTEXT.md` and `14-RESEARCH.md` specify all behavioral boundaries explicitly, this plan treats the following edge cases as verified assumptions:
  1. **Short timer (< fade_duration):** If remaining time `T` is shorter than `sleep_timer_fade_duration`, fade begins immediately using `actual_fade = max(0.0, plugin._sleep_timer_end - time.time())` (per D-01).
  2. **Missing `_volume_fader` or `_settings` on lightweight test mocks:** `sleep_timer_worker` and `get_sleep_timer_status` use `getattr(plugin, "_volume_fader", None)`, `getattr(plugin, "_settings", {})`, and `getattr(plugin, "_sleep_timer_fading", False)` so existing unit tests without a fader continue passing.
  3. **Audio drain delay:** `1.2s` `asyncio.sleep(1.2)` between `control_playback("pause")` and `release_sleep_lock(0.0, wait=True)` prevents PipeWire buffer pops and ensures `module-stream-restore` persists baseline volume before `shutdown_system()`.
</note>
