## Interaction Contracts

### 1. Gamescope HUD Lyric Row (`src/components/DeckifyOverlay.tsx`)
- **Input Safety (`HUD-04`):** Root `.deckify-ingame-overlay` container MUST strictly preserve `pointerEvents: "none"` so gameplay and touchscreen inputs never stall.
- **Placement & Fixed Geometry (D-01, D-02):**
  - Rendered full-width below the artwork + title/artist header and above the `2px` progress bar, only when `lyricsEnabled === true`.
  - Fixed height `18px` (`lineHeight: "18px"`), `fontSize: 11`, `whiteSpace: "nowrap"`, `overflow: "hidden"`, `textOverflow: "ellipsis"`, `borderTop: "1px solid rgba(255, 255, 255, 0.08)"`, `paddingTop: 4`, `marginTop: 4`.
  - GPU-composited `200ms` CSS opacity cross-fade (`@keyframes deckifyLyricFadeIn { from { opacity: 0; } to { opacity: 1; } }`) triggered via React `key` on the inner lyric `<span>` when the active line changes.
- **Discrete Event Scheduling (`HUD-04`, D-04, D-05):**
  - Zero `setInterval` or `requestAnimationFrame` loops.
  - Anchor `positionMs` to `Date.now()` in `posAnchorRef` whenever `positionMs`, `isPlaying`, or track identity changes.
  - Compute `effectivePosMs = posAnchorRef.current.posMs + Math.max(0, Date.now() - posAnchorRef.current.atMs) + lyricsOffsetMs`.
  - Find the last `SyncedLine` where `line.timeMs <= effectivePosMs` and schedule a single `setTimeout` for `Math.max(16, nextLine.timeMs - effectivePosMs)`.
  - Reschedule immediately on track change, seek (`positionMs` change), play/pause toggle, or `lyricsOffsetMs` change.
- **Pause Grace & Slot Priority (D-03, D-06, D-07):**
  - When `!isPlaying`: clear pending lyric `setTimeout`, freeze `activeLineIndex`, and dim the lyric row to `opacity: 0.5` during the `3500ms` pause grace window.
  - Display priority inside the fixed `18px` slot:
    1. `syncedLyrics.length === 0 && lyricsLoaded` → `"No synced lyrics"` (`rgba(255, 255, 255, 0.55)`)
    2. Loading (`!lyricsLoaded`) or `activeLineIndex < 0` → `"♪ •••"` (`rgba(255, 255, 255, 0.55)`)
    3. `activeLineIndex >= 0` → `syncedLyrics[activeLineIndex].text` (`rgba(255, 255, 255, 0.90)`)

### 2. Autohide, Configurable Duration & Modal Suppression (`src/components/DeckifyOverlay.tsx`, `src/index.tsx`)
- **Strict `autoHide` Respect (D-08):** When `autoHide` is `false` and `isPlaying` is `true`, `hideTimerRef` MUST NOT be scheduled and the HUD remains continuously visible. When `autoHide` is `true`, HUD hides after `autoHideDurationMs` (`(overlay_autohide_duration_s ?? 6) * 1000`, clamped `3000..15000`), re-appearing on track change.
- **Modal-Open Suppression (D-10):** `DeckifyOverlayWrapper` subscribes to `modalOpenListeners` (synced with `bigOpen` / `DeckifyExpandedModal` mount/unmount) and passes `visible={Boolean(settings.overlay_enabled) && !modalOpen}`. When `/deckify` modal closes, `DeckifyOverlay` restores visibility and starts a fresh autohide timer if `autoHide` is enabled.
- **Conditional RPC Gating:** `DeckifyOverlayWrapper` calls `backendGetLyrics(title, artist, dur, 0)` ONLY when `settings.overlay_enabled && settings.overlay_lyrics_enabled` is `true`, deduplicated by track key ref.

### 3. QAM & SettingsTab Controls (`src/index.tsx`, `src/components/tabs/SettingsTab.tsx`)
- **QAM (`src/index.tsx` `renderOverlayControls`):**
  - Keep QAM compact (no sliders in QAM per D-12).
  - Add `ToggleField` for `Overlay Lyrics` (`label="Overlay Lyrics"`, `description="Show live synced lyric line in HUD"`) inside the `settings.overlay_enabled` block.
  - Update `Auto-Hide Overlay` label to reflect configured duration (`Auto-Hide Overlay (${settings.overlay_autohide_duration_s ?? 6}s)`).
- **`SettingsTab.tsx` (In-Game Mini Overlay (HUD) card):**
  - `Overlay Lyrics` toggle (`overlay_lyrics_enabled`, default `false`) (D-11).
  - `Auto-Hide Duration (Seconds)` `SliderField`: `min={3}`, `max={15}`, `step={1}`, `showValue`, default `6` (`overlay_autohide_duration_s`) (D-09).
  - `Lyrics Latency Offset (ms)` `SliderField`: `min={-2000}`, `max={2000}`, `step={100}`, `showValue`, default `0` (`overlay_lyrics_offset_ms`) (D-12).

### 4. Clickable Lyrics Source Pills (`src/components/tabs/LyricsTab.tsx`)
- Render 5 clickable source pills (`Spotify`, `LRCLIB`, `NetEase`, `Musixmatch`, `Lyrics.ovh` mapped to provider offsets `0..4`) inside `<Focusable flow-children="horizontal" style={{ display: "flex", gap: 8, flexWrap: "wrap", alignItems: "center" }}>` (D-13).
- Active pill matching `lyricsSource` receives `#1db954` text and `rgba(29, 185, 84, 0.2)` background; inactive pills use `rgba(255, 255, 255, 0.08)`.
- Retain `"Try Next Source"` `InteractiveRow` alongside the pills as a sequential fallback cycle.
