## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Inline icon gaps, 2-line card title-to-subtitle gap, badge padding |
| sm | 8px | Time-range pill spacing, card internal padding, header status badge gap |
| md | 16px | Horizontal carousel card gap (`gap: 16`), section header bottom margin |
| lg | 24px | Vertical spacing between carousels, main content pane padding |
| xl | 32px | Empty / error / re-auth state card padding |
| 2xl | 48px | Major vertical section breaks |
| 3xl | 64px | Page-level bottom scroll clearance |

Exceptions:
- Square carousel artwork cards use `128px × 128px` (`DeckifyImage`) for crisp legibility on the Steam Deck 1280×800 display.
- Interactive filter pills (`4 Weeks`, `6 Months`, `All Time`) and `Refresh Feed` button maintain a minimum `32px` height and `8px 16px` padding for comfortable D-pad and touchscreen targeting.

## Layout & Controller Interaction Contract

1. **Sidebar & Default Landing (`D-01`, `D-02`):**
   - `Discovery` (`ViewMode: "discovery"`) appears in `Sidebar.tsx` directly after `Now Playing` and `Lyrics` at the top of the Browse section.
   - When opening `DeckifyExpandedModal`: default to `now_playing` if playback is active (`status?.track || status?.track_meta` with active playback); default to `discovery` when nothing is playing.
2. **Header & Shared Controls (`D-03`, `D-07`, `D-09`):**
   - Top row displays the time-of-day contextual greeting (`Good morning` 05:00–11:59, `Good afternoon` 12:00–17:59, `Good evening` 18:00–04:59) on the left and the compact `Refresh Feed` button on the right.
   - Directly below the greeting, a shared horizontal `<Focusable flow-children="horizontal">` time-range pill bar (`4 Weeks` / `6 Months` / `All Time` mapping to `short_term` / `medium_term` / `long_term`, default `6 Months`) updates both `Top Tracks` and `Top Artists` together.
   - When `stale === true` or `rate_limited === true` with cached data, render a subtle `#1C1C1C` banner displaying `"Rate limited — showing cached feed"`.
3. **Carousel Order & Card Anatomy (`D-03`, `D-04`, `D-05`):**
   - Vertical stack order: (1) `Made For You` (with `Jump Back In` fallback if user follows no `owner.id === "spotify"` mixes), (2) `Top Tracks`, (3) `Top Artists`, (4) `New Releases`.
   - Each carousel uses `<Focusable flow-children="horizontal">` (never `"row"`) with `10–15` square `128px × 128px` artwork cards (`<DeckifyImage src={url} />`), 2-line title (`13px`), and 1-line subtitle (`11px`, `opacity: 0.65`).
   - Focused cards call `scrollIntoView({ behavior: "smooth", inline: "nearest", block: "nearest" })` so horizontal D-pad navigation stays centered and visible.
4. **Card Actions (`D-08`):**
   - `A` press on **Top Track**: plays immediately with the Top Tracks URIs sequence so Next/Prev work.
   - `A` press on **Top Artist**: drills into the Artist detail view.
   - `A` press on **Mix / Playlist / Album**: drills into the Playlist or Album tracklist view.
   - `Y` press on **Top Track**: opens `TrackActionModal` (Like, Add to Queue, Add to Playlist).
   - `Y` press on **Mix / Playlist / Album**: opens `CollectionActionModal` (Quick Play, Pin to QAM).

## UI Considerations

Applicable state considerations resolved: 6 covered, 1 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| `empty` | `DiscoveryTab` feed & individual carousels | ✅ covered | Empty Made For You falls back to `Jump Back In` (recently played contexts); completely empty feed renders the documented `No personalized recommendations yet` copy and `Refresh Feed` CTA. |
| `loading` | `DiscoveryTab` initial load & `Refresh Feed` | ✅ covered | Displays loading state while `get_discovery_feed` is in flight and disables duplicate `Refresh Feed` submissions until resolved. |
| `error` | HTTP 429 circuit breaker & HTTP 403 scope v7 | ✅ covered | 429 with stale cache renders `"Rate limited — showing cached feed"` banner + cached cards; 429 without cache renders cooldown error copy; 403 on `/me/top/*` renders `"Re-authenticate to unlock Top Tracks & Top Artists"` card while keeping Made For You and New Releases functional. |
| `populated` | 4 horizontal carousels (`10–15` cards each) | ✅ covered | Renders `Made For You`, `Top Tracks`, `Top Artists`, and `New Releases` using `128px × 128px` `<DeckifyImage>` cards inside `<Focusable flow-children="horizontal">`. |
| `partial` | Mixed endpoint availability | ✅ covered | Each carousel degrades independently; a 403 or empty response on one section does not block rendering of other populated sections. |
| `overflow` | Horizontal card strip & vertical scroll | ✅ covered | Horizontal carousels scroll horizontally via `scrollIntoView({ inline: "nearest" })` on gamepad focus; vertical stack scrolls inside `contentPaneRef`. |
| `long-text` | Card titles & subtitles | 🧪 backstop | Card titles clamp to 2 lines (`WebkitLineClamp: 2`, `textOverflow: "ellipsis"`) and subtitles clamp to 1 line to preserve uniform card height across carousels. |
