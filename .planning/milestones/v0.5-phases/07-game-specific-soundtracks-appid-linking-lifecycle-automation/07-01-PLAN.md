    Implement pure Python standard library Steam VDF and shortcut discovery in `py_modules/vdf_parser.py` per D-03 and D-07:
    1. Implement `parse_binary_vdf(data: bytes) -> dict`:
       - Parse Valve KeyValues binary format (`shortcuts.vdf`) iteratively using little-endian byte unpacking via `struct` and null-terminated string reading.
       - Handle type bytes: 0 (sub-dictionary), 1 (string), 2 (int32 `<i`), 3 (float32 `<f`), 7 (int64 `<q`), and 8 (end of dictionary).
       - Provide graceful error recovery: catch `struct.error` or EOF bounds exceptions and return partial dictionary rather than crashing.
    2. Implement `compute_non_steam_appid(exe: str, app_name: str, raw_appid: int | None = None) -> int`:
       - If `raw_appid` is provided and non-zero, unpack as unsigned 32-bit int `<I` from signed int32 `<i` to prevent sign inversion.
       - Otherwise, calculate `zlib.crc32(f"{exe}{app_name}".encode("utf-8")) & 0xFFFFFFFF`, and apply top-bit mask: `(crc | 0x80000000) & 0xFFFFFFFF`.
       - Return strictly positive unsigned 32-bit integer matching `SteamClient.Apps.RegisterForAppLifetimeNotifications` `unAppID`.
    3. Implement `parse_text_vdf(content: str) -> dict`:
       - Lightweight regex-based text KeyValues parser for `libraryfolders.vdf` and `appmanifest_*.acf` files to extract `path`, `appid`, `name`, and `installdir`.
    4. Implement `get_installed_games(force_refresh: bool = False) -> list[dict]`:
       - Implement 30-second TTL in-memory caching using `time.monotonic()` to avoid disk thrashing.
       - Scan Steam native library folders: read `~/.local/share/Steam/steamapps/libraryfolders.vdf`, enumerate all mounted libraries, and scan `appmanifest_*.acf` to extract Steam games with `app_id` (int), `name` (str), `is_steam: True`, and `icon_url` (Steam CDN capsule format).
       - Scan Non-Steam shortcuts: scan `~/.local/share/Steam/userdata/*/config/shortcuts.vdf`, parse using `parse_binary_vdf`, extract shortcuts with `app_id` (from `compute_non_steam_appid`), `name`, `exe`, `is_steam: False`, and mark with `is_non_steam: True`.
       - Return unified list sorted alphabetically by `name`.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SteamOS Filesystem → Python Daemon | Steam `shortcuts.vdf` and `libraryfolders.vdf` parsed from user space; untrusted/corrupt data crosses here. |
| CEF Frontend RPC → Python Daemon | `app_id` and profile JSON structures sent over WebSocket RPC from GamepadUI frontend. |
| Python Daemon → Spotify Web API | Outbound HTTPS requests sending play, seek, and pause commands with OAuth Bearer tokens. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Denial of Service | `py_modules/vdf_parser.py` | medium | mitigate | Add strict bounds checking in `parse_binary_vdf`, catch `struct.error` and `IndexError`, and throttle filesystem access with a 30s in-memory TTL cache to prevent CPU/IO exhaustion on large libraries. |
| T-07-02 | Tampering | `main.py` (RPC router) | high | mitigate | Explicitly cast and validate `app_id` as positive 32-bit unsigned integer, validate profile schema keys against expected whitelist, and reject negative or non-integer identifiers. |
| T-07-03 | Information Disclosure | `py_modules/soundtrack.py` | low | mitigate | Store only track URI, context URI, and millisecond seek offsets in pre-game snapshots; never serialize OAuth tokens or private user keys into `settings.json`. |
| T-07-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero new external dependencies. Standard library (`struct`, `zlib`, `asyncio`, `json`, `os`, `re`) used exclusively for VDF parsing and lifecycle automation. |
